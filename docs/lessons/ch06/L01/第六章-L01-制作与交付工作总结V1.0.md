# 第六章 L01 制作与交付工作总结 V1.0

整理日期：2026-10-26。

本轮围绕《第6章-L01完整口播稿V0.3》完成了分段视频制作、整课导出、四项媒体交付和配套讲义制作。各内容样段及有声字幕成片已获用户审核通过；6 页讲义样稿已通过，34 页整课讲义已交付、待用户审核。

## 一 工作起点与范围

工作从了解 `course-video-pipeline-codex` 项目开始。项目已有 DeepSeek 参与制作的内容与阶段文档，用户希望基于第六章 L01 的既有口播稿制作一版视频，先了解项目，不立即修改代码。

随后明确的目标是：让视频讲得清楚、展示自然，并通过分步沟通尽早发现问题，避免等到整片完成后大规模返工。DeepSeek 的阶段文档仅供参考，不要求照搬其文档形式，也不以重新设计工程体系为目标。

口播依据为 [第6章-L01完整口播稿V0.3.md](/projects/gaoxiang/course-video-pipeline-codex/docs/lessons/ch06/L01/input/第6章-L01完整口播稿V0.3.md)。视频保留已确认口播的原文与顺序；屏幕文字按教学需要提炼为标题、关键词、图解和完整题面。制作期间遇到真题材料差异，先核对材料，由用户修改并确认口播稿后再继续相应片段。

最初项目查看中提及的第七章旧交接文档问题，属于背景发现，没有纳入本轮第六章制作任务。

## 二 已确认的协作要求

1. 优先做直接有利于视频展示的工作，不提前引入工程化，不自行扩大范围。
2. 分步制作、及时反馈，不要求一次完成整片；重要画面和样段先交用户审核。
3. 遇到困难及时说明，尤其是材料冲突、音质异常、展示效果和配音衔接问题。
4. 适合 GPU 加速的工作优先使用 RTX 5060 Ti 16GB；若需要用户执行命令，说明具体原因、操作和所需反馈。
5. 用户已通过的样式和内容继续沿用；新建议与已批准的修改分别记录。

上述前四项已写入项目 [AGENTS.md](/projects/gaoxiang/course-video-pipeline-codex/AGENTS.md)。

## 三 制作过程与主要反馈落实

### 先确认展示方向，再逐段展开

先以“项目定义与组织状态转换”样段建立视觉基线，再讨论整课画面安排。对容易产生理解偏差的真题和教材关系图先做样段，获得反馈后继续制作其他内容。各阶段通过后，才进入整课串联和最终导出。

全课内容按口播顺序组织为：

| 内容 | 主要展示方式 |
| --- | --- |
| 开场、考情与 PMBOK 演进 | 学习路线、考情数字、版本时间轴、第六版与第七版对照 |
| 项目定义与作用 | 定义关键词、组织当前状态到将来状态的转换图 |
| 独特性、临时性与结束条件 | 项目对比、起止边界、易错点、成果延续、结束情形 |
| 战略价值与成功标准 | 项目成果与业务目标的联系、交付表现与业务价值双维度 |
| 项目组合、项目集、项目与运营 | 总体关系图、依赖协调、范围渐进明晰、成果与资源交接 |
| OPA 与 EEF | 区分线索、组织过程资产、内部与外部环境三栏对照 |
| 组织系统与产品生命周期 | 组织结构光谱、三类 PMO、产品生命周期图 |
| 五道真题 | 完整题面、独立思考、逐项讲解、答案与归纳 |
| 结课 | 本课回顾与 L02 项目经理预告 |

### 教材图形与画面样式

- 对照教材图 6-1 至图 6-4，以及相关表格设计教学画面。
- 按用户建议，图形的大小和位置服务于讲解：可占据大部分内容区，也可与文字左右分栏或局部展示，不固定为每图满屏。
- 沿用深蓝背景、青色与金色重点、半透明卡片。用户反馈选项与解析像“贴上去”后，降低相关底板的不透明感，使其与背景更自然地融合。
- 移除“依据教材重绘”“结构画面稿”等内部制作说明，学生画面只保留教学信息。
- 对齐既有 [视频头尾区域规范V0.1.md](/projects/gaoxiang/course-video-pipeline-codex/docs/architecture/视频头尾区域规范V0.1.md) 与 [字幕规范V0.1.md](/projects/gaoxiang/course-video-pipeline-codex/docs/architecture/字幕规范V0.1.md)。
- 开场主标题改为“第六章 项目管理概论”，美化后获用户认可，并单独形成 [章节主标题样式规范V0.1.md](/projects/gaoxiang/course-video-pipeline-codex/docs/architecture/章节主标题样式规范V0.1.md)。规范仅覆盖该标题样式。

### 真题核对与答案揭示

- 五道题分别设置 3 秒真实静音倒计时，供学生独立作答；倒计时期间不显示口播字幕。
- 读题和思考阶段使用中性题面，不通过颜色、勾叉、重点词、解析文字或字幕提前泄露答案。
- 阅读焦点、判对判错、最终答案分别跟随对应口播出现；答案短语必要时单独拆分字幕。
- 第 69 题曾出现口播稿与本地题库选项不一致的情况。用户明确要求先核对原题，随后修改口播稿，再按确认后的内容制作。
- 第 29 题 C 项按用户确认：题面保留题库原文“组织的问题、风险、变更”，口播保留“问题、风险、变更管理程序”作为讲解补充。

### 配音与字幕

用户指出第一道真题约 1:07、“周而复始”附近语音失真。该问题通过局部重新分句生成配音处理，并重新对齐字幕及答案揭示时间，保留原文字句。后续样段和整课继续经过用户试听审核。

整课使用一条连续音轨，避免各样段音频重复播放；保留真题思考停顿，去掉独立审核预览额外增加的段尾停留。完整 SRT 按整课时间轴生成，共 315 条字幕。

## 四 视频成片与媒体交付

整课由 11 个内容段组成，共 66 个场景，35369 帧。输出为 1920×1080、30fps，时长约 19 分 39 秒。

“66 个场景”表示 66 个讲解画面段落，不是 66 张静态图片。一个场景中可包含文字展开、图形动画、选项分析等变化。

交付目录：[deliverables/ch06-L01](/projects/gaoxiang/course-video-pipeline-codex/deliverables/ch06-L01)。

| 交付物 | 文件 | 状态与用途 |
| --- | --- | --- |
| 有声口播字幕视频 | `ch06-L01-voiced-captioned.mp4` | 已导出，用户审核通过 |
| 完整音频 | `ch06-L01-full.wav` | 已归入交付目录，与整课使用的原音轨一致 |
| SRT 字幕 | `ch06-L01.srt` | 已导出，315 条，按整课时间轴排列 |
| 无声无口播字幕视频 | `ch06-L01-silent-clean.mp4` | 已按要求补导出；保留教学文字、图形、题面、解析和倒计时 |

两个视频的画面帧数与时长一致，WAV 与整课时间轴对齐。无声版只有视频轨道，没有音轨；“无字幕”仅指移除底部口播字幕，不移除画面中的教学文字。

`media-info.json` 和 `media-info-silent-clean.json` 是导出后生成的媒体参数记录，分别对应两版视频，记录时长、分辨率、帧率、编码及轨道等信息。它们用于查验，不参与播放。

视频导出使用了 GPU 编码加速。已核对实际输出的媒体参数，并抽看导出视频的代表画面；用户审核是视觉与听感验收的重要依据，参数检查不替代人工观看。

整课预览入口为 `http://localhost:3026/Ch06L01Full`，无声版入口为 `http://localhost:3026/Ch06L01SilentClean`；本地预览需要服务运行。
