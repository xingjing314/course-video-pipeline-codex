## 四、三个关键取舍

| # | 取舍 | 理由 |
| :---: | :--- | :--- |
| 1 | **累积而不是替换**：已填行保留 55% | "身份证"隐喻要求终态是一张填满的卡；若一行一屏，S21 讲完时学生脑子里没有完整卡片，回看时也接不上 |
| 2 | **未点亮行只露栏名** | 制造"待填"缺口，让讲师每讲一条都是"补上一个空"，而不是"再念一行字" |
| 3 | **刻度尺里放入「可行性研究」当路标** | 学生最常问"建议书和可研是什么关系"。把可研摆在设想之后、实施计划之前，断层线落在设想与可研之间——一句话说明"此刻连可研都还没开始" |

另外两个细节：

- **两个 ✕ 不写成"选项 A/B"**，而是红框签。它们和真题题干里的错误表述同构（"国家监管部门""乙方承建单位"），看过 A7 的学生一眼认出这是"命题人会写错的地方"。
- **外资特例做成虚线「附」条**，字号比正文小一级。它是低频点，只求"见过"，不能和三行主信息抢层级。
