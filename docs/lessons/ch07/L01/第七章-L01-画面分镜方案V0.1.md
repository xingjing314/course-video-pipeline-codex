## 二、视觉系统（一次定死，全片复用）

### 2.1 画幅与栅格

| 项 | 规格 |
| :--- | :--- |
| 画幅 / 帧率 | 1920×1080，30 fps（Remotion 默认；如需 25 fps 只改一处配置） |
| 安全区 | 左右各 96 px，上下各 72 px；正文有效区 1728×936 |
| 栅格 | 12 列，列宽 120 px，槽宽 24 px（合计 1704 px，在 1728 px 有效区内左右各余 12 px） |
| 讲师层 | **默认无出镜**。右下角预留 480×270 空位（x=1344, y=738），所有版式的正文与关键标注**不进入该区域**，以便后续加"讲师小窗"无需重排 |
| 底部字幕带 | 距底 48 px，高度 64 px，全宽 1728 px |

### 2.2 色彩语义（一种颜色只表达一件事，不得混用）

| 色 | 值 | 唯一含义 | 出现场景 |
| :--- | :--- | :--- | :--- |
| 墨蓝（底） | `#0E1626` / 面板 `#16223A` | 背景与容器 | 全片 |
| 纸白 | `#F2F5FA` | 正文与题干 | 全片 |
| **金** | `#E8B54B` | **必背考点 / 口诀 / 正确答案** | S02、S12、S16、S27、S30 |
| **朱** | `#E4572E` | **陷阱 / 干扰项 / 错误表述** | S10、S16、S19、S20、S24、S25、S28 |
| 青 | `#3FB6C8` | 流程、阶段、中性强调 | S05、S08、S09、S11、S13、S31 |
| 绿 | `#4CAF7D` | 通过、批复、勾选 | S16、S25、S31 |
| 灰 | `#6B7A90` | 已跳过 / 非当前焦点 | S12、S13、S24 |

> 判断标准：屏幕上只要出现金色，就必须是"考试要记的"；只要出现朱色，就必须是"命题人要坑你的"。学生看三分钟就能建立条件反射，这是本课视觉设计的第一目标。

> **落地口径（V0.1 原型后补）**：上表是**语义定义**，实际色值以项目 `colorCard` v1.1 tokens 为准——`#0B1A33`（底）/ `#E6F1FA`（字）/ `#E0B050`（金）/ `#E0605A`（朱）/ `#2EC4D6`（青）/ `#4CC38A`（绿）/ `#8FB8D9`（灰）。A5 原型已按 tokens 实现，见 [A5 原型说明](第七章-L01-A5四关轨道-原型说明V0.1.md)。

### 2.3 字体层级

| 层级 | 字号 / 字重 | 用途 |
| :--- | :--- | :--- |
| H1 | 88 / Bold | 章节标题（仅 S01） |
| H2 | 64 / Bold | 关卡名、口诀主字 |
| H3 | 44 / SemiBold | 卡片标题、真题题干 |
| 正文 | 36 / Regular | 说明、选项 |
| 注释 | 26 / Regular | 批注、角标、来源 |
| 数字 | 72 / Bold，等宽数字 | 考情数据 |

行宽上限 **≤ 25 全角字**，单屏文字行 **≤ 6 行**。超出即拆镜——宁可多切一刀，不可让画面变成 PPT 段落。

### 2.4 动效语言（全片只有 4 种，禁止临时发明）

| 名称 | 参数 | 用途 |
| :--- | :--- | :--- |
| `fadeUp` | 位移 +12 px，透明度 0→1，0.35 s，`cubic-bezier(.2,.8,.2,1)` | 一切元素的默认入场 |
| `pop` | 缩放 1.00→1.06→1.00，0.25 s | 强调当前焦点 |
| `strike` | 沿元素长度描线，0.30 s | 划掉干扰项、标注错误表述 |
| `stamp` | 缩放 1.35→1.00 + 0.06 s 微震，0.35 s | 盖章：不可缺少 / 批复同意 |

- 单镜动效 **≤ 3 组**；同屏元素入场间隔 **0.10–0.15 s**。
- 停留期（讲师讲完一句、画面不动）**≥ 1.5 s**，避免"画面比嘴快"。

### 2.5 转场

| 层级 | 规则 |
| :--- | :--- |
| 镜内 | **硬切**，不加任何转场 |
| 段间（8 段） | 0.40 s 横向推移（左进右出），方向统一向右，暗示"往前走" |
| 真题进出 | 0.30 s 暗场遮罩（黑场 6 帧），把"上课"与"做题"两种心理状态切开 |

### 2.6 声音与字幕

| 项 | 规则 |
| :--- | :--- |
| BGM | 全片垫底，`-30 dB`，无鼓点、无人声；真题段降至 `-34 dB` |
| 音效 | 仅 4 个：卡片入场 `tick`、落章 `thud`、正确 `chime`、错误 `buzz`。**同一时刻只响 1 个**；判卷动作可成对出现（先 `buzz` 判错、后 `chime` 判对） |
| 关键词浮层 | 底部 64 px 带内，≤ 14 字，金色，与口播同步出现（不是逐字字幕） |
| 全文软字幕 | 另出 `.srt`，默认关闭；理由：本课信息密度高，全文字幕会与板书争夺注意力 |

### 2.7 讲师层（可选，非本版必须）

若后续决定出镜：右下 480×270 圆角小窗，安全区已预留；小窗出现时，右下角 300×300 范围的画面元素自动上移。**本方案所有详设均按"无出镜"绘制**，加小窗不会破坏版式。

## 三、时间预算

基准：**4.3 字/秒（258 字/分）**，去标点计 2145 字 → 498.8 s；加 4 处刻意留白（S14 后 2 s、S15 2 s、S23 2 s、S29 1.5 s）→ **507 s ≈ 8:27**。

> 校正公式：`新时长 = 原时长 × (实测字数速率 / 4.3)`。若 TTS 语速为 4.0 字/秒，全片变为约 9:05，各镜按比例放大，**镜头切点相对位置不变**。

## 八、独立判断说明与风险

### 8.1 五条设计取舍（与旧稿的差异及理由）

| # | 取舍 | 理由 |
| :---: | :--- | :--- |
| 1 | **"四关轨道"替代旧稿的"漏斗/阶梯"** | 口播三次说"关"（四步闯关、第一关、第二关），"关"才是口播的隐喻；漏斗暗示"筛选淘汰"，与"逐关通过、盖章放行"的语义相反。轨道还能一路走到 S31 把学生送进 7.2 |
| 2 | **一图到底，而不是一段一图** | 全片 10 个资产里，只有 A5 是 L 级；7 个镜头共用它。既降低学生每次换图的认知重载，也把制作成本压到最低——这是"方案"阶段最该算的账 |
| 3 | **真题卡做成固定模板 + 固定判卷语法** | 同一套"划叉→灰化→高亮"动作重复 6 次，学生到第 3 题就不需要再学"怎么看画面"，注意力全部回到知识 |
| 4 | **默认无讲师出镜，但预留 480×270 安全区** | 口播是单向讲授、无对话场景，硬加出镜只会挤压板书空间；但出镜是后续可能的需求，所以版式先让位，避免返工 |
| 5 | **关键词浮层为主，全文软字幕默认关闭** | 本课信息密度高（8 分钟 2145 字），全文字幕会与板书争抢注意力；但保留 `.srt` 作为无障碍与二次剪辑资产 |
