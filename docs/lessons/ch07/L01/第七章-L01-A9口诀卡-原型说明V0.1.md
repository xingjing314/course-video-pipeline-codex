## 一、结论

**口诀卡从"逐字点亮"改成"整句入场 + 一次扫光 + 四卡分拍"。**

原分镜写的是"9 个字符逐个描金"，本版去掉逐字：三句口诀作为三个整体依次入场（0.12s 错峰），整条口诀只做**一次**从左到右的扫光，此后不再逐字动。理由很实在——逐字描金把 3 秒的注意力全花在"看字一个个亮"上，而这句话本身没有理解难度；金子应该花在"四项内容怎么对应三句口诀"上，那才是真正要记的东西。

所以这一版把动画预算换了地方：**四张卡逐张点亮，每张卡自带「属于哪一句」的金色小签**。学生看到的不是"字亮了"，而是"① 归『一必要』、②③ 归『两市场』、④ 归『一条件』"——这才是考场上要还原的映射。

- 评审片：`out/a9/a9-mnemonic.mp4`（580 帧 / 30fps / 19.3 秒 / 静音）
- 关键帧：`out/a9/a9-1-intro.png`（口诀入场）、`a9-2-two.png`（讲 ②③）、`a9-3-all.png`（全亮）

## 四、三个取舍

| # | 取舍 | 理由 |
| :---: | :--- | :--- |
| 1 | **去掉逐字描金，改成整句扫光** | 见第一节。逐字是"表演"，扫光只是"确认这句话到了"，把时间留给四卡映射 |
| 2 | **每卡挂「属于哪一句」小签** | 三句口诀对四项内容不是一一对应（两市场 → ②③）。小签把这条"一对多"钉在卡上，比讲师口头解释省 10 秒 |
| 3 | **第 ③ 卡不换口诀高亮** | ③ 与 ② 同属"两市场"，讲 ③ 时"两市场"保持高亮不切换——如果切走，学生会以为 ③ 属于别的口诀 |

另外两个细节：

- **未点亮的卡保留到 35%**，不隐藏。四张卡的骨架一直在，学生能预判"还有几张没讲"，这和 A8 的"待填"是同一套语言。
- **底部口径条在第 2 阶段才淡入**，不在开场就压住画面；它服务于 S28 的"命题套路"，提前出现会抢 ① 的注意力。

## 五、背景统一说明

按你的要求，四个原型（A5 / A7 / A8 / A9）现在都统一挂 `TechNetwork` 背景：

- 背景只挂在 **Lab 编排层**，不挂在资产组件里。因为正式片里 `MasterCanvas` 已经全局挂了一层背景，资产再挂一层会重影。
- A5 / A7 / A8 的评审片已按新背景重渲；资产本身的几何、动效一律未改。

> **但要说清楚**：背景本来就该**最后统一换**。它只活在 Lab 与 `MasterCanvas` 这一层，资产组件是透明底、与背景无关；所以换背景不需要动任何资产，也不该每次改资产都连带重渲一遍。这次为了让你直接看到成片效果先挂了，代价是 A7 体积从 4MB 涨到 79MB（科技网格细节多、同码率下体积翻倍）。正式出片时按交付标准压一次即可。
