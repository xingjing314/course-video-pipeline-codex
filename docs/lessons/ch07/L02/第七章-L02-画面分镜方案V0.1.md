### 2.8 顶部导航（HeaderBreadcrumb）规范

> 这一节是**硬规则**，不是建议。L02 之后的每一课都照此执行；L01 已验收，**不回改**。

#### 结构：三段式

| 位置 | 内容 | 示例（本课 S13） |
| :--- | :--- | :--- |
| 左上 · 徽章 | 课程编号，大写 | `CH07-L02` |
| 左上 · 课名 | 固定格式：`第 X 章 <章名> · Lxx` | `第 7 章 项目立项管理 · L02` |
| 左上下方 · 小节行（eyebrow） | 自由标签，**最多到三级编号** | `7.2.1 五大可行性维度` |
| 右上 · 段名 | 当前所属段的短名（9 段见下表） | `技术四因素` |
| 右上 · 镜号 | `Sxx · 序号/总镜数` | `S13 · 13/42` |

#### 规则

1. **左上第 1 行永远不变**：整课只有一对值（`CH07-L02` + `第 7 章 项目立项管理 · L02`），任何镜头都不许改。
2. **小节行允许自由命名，但编号最多到三级**：`7.2` ✓、`7.2.1` ✓、`7.2.1-1` ✗。像「五顶帽子」「终极防坑表」这类短语可以直接用，不必强行编号。
3. **镜号分母用本课自己的总镜数**（L02 = 42），不要求与 L01 的 31 一致。分母只表达"这一课有多长"，不承担跨课比较的职责。
4. **右上段名随段切换**，同段内不变；镜号随镜切换，每镜都变。
5. **有声版与静音纯净版都显示 header**——它属于教学文字结构，不属于字幕层（`CaptionsOverlay` 才是字幕层）。

#### 几何（已实测，2026-10-25）

渲染 `S13` 实帧，逐行扫描左上文字像素：

| 元素 | 容器 | 实际字形占位 |
| :--- | :--- | :--- |
| HeaderBreadcrumb | `top: 14`，`height: 32`（→14–46） | **24–38** |
| SceneShell eyebrow | 标题块 `top: 48` 起 | **53–72** |

**实际间隙 14px**（≥ 8px 目标），无需下移 `top`、也无需缩小字号。

> 注意：容器算出来只隔 2px，但字形行高留白补足了——**以实测为准，不以容器边界为准**。这条经验对后续每课都适用。

#### 数据来源（实现方式）

- header 由**章节段组件自己渲染**（`headerMode: "chapter"`），因为它要在跨镜段内随帧推进；
- 每镜的 `sceneId / order / segmentTitle` 来自段表（`span-timeline`），不在组件里写死；
- 总镜数 42 由段表长度汇总，不手填。

L01 已验收，存在 6 处与本节不一致的 eyebrow（`四笔账`、`全书坐标`、`全章骨架`、`命题套路`、`7.1.2 只有一句话`、`7.1.1 立项申请概念`）。**保留原样，不回改**——改一处就要重渲整片，收益不抵成本。L02 起按本节执行。

## 八·六、验收问题与修复（2026-10-25 15:30）

**问题**：成片里反复出现"旁白还在念选项、画面已经把答案揭开"——题目讲解尤其明显。
