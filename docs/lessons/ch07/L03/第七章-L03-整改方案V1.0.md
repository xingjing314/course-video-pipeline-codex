# 第七章 L03｜整改方案 V1.0

> **触发**：L03 成片评审未通过，累计发现 19 项问题（含 1 项音频事故、1 项泄题 bug、1 项分镜粒度错误、3 项题目画面缺失）。
> **原则**：先修"会让内容错"的（音频、泄题），再修"让人看不懂"的（布局、缺题），最后修"不够好看"的（动画、样式）。
> **关键约束**：改分镜 ⇒ 必须重跑该段 TTS；只改组件 ⇒ 只需重渲染。**能合并成一次的，不跑两次。**

---

## 一、结论先行

| 类别 | 数量 | 是否影响音频 | 是否影响时长 |
| :--- | ---: | :---: | :---: |
| 音频/字幕事故 | 2 | **是** | **是**（约 −28 s） |
| 分镜粒度（S44 拆镜） | 3 | **是** | **是**（拆镜后不变，但场景文本变） |
| 题卡交互（双题/泄题/缺题） | **7** | 否 | 可能（若为 23下4 T23 加第 8 处停顿则 +3 s） |
| 静态清单（铁三角/依据/大纲/六步） | 4 | 否 | 否 |
| 工程约束缺失 | 3 | 否 | 否 |

**执行结论**：把"影响音频"的 5 项（A1、B1–B3）合并成**一次** TTS 重跑；其余 12 项只改组件，最后**一次**渲染。

## 六、逐项实现要点

### A1 · 音频修复

- 缓存键 = `clause-pause-v1.1|20261024|<instruct>|<clause text>`；坏文件是 `2fd59ba574b0….wav`（31.93 s）
- 重跑命令：`node --experimental-strip-types scripts/run-l01-audio.ts --lesson=ch07-L03-ds --mode=cuda`
- 校验：`ffprobe audio/S45.wav` ≈ 9 s；S45 字幕 ≥ 3 条且覆盖到场景末

### A2 · 分句体检

- 位置：`src/pipeline/2-audio/audio-runner.ts`，TTS 返回后逐分句检查
- 规则：`durationSec / visibleChars > 1.5` 即抛错，并打印 sceneId + 分句 + 时长
- 副作用：无（仅在异常时中断）

### B1–B3 · S44 拆镜

| 新镜 | 口播 | 画面 |
| :--- | :--- | :--- |
| S44a | L91（43 字） | 四关平铺、全部压暗，标题"总图" |
| S44b | L93（52 字） | 第一关放大：框架性总体设想 / 一必要两市场一条件 / 交给上级主管部门 |
| S44c | L94 前半（~80 字） | 初可研 ±20% 与详可研 ±10% 并置 + "有无比较法 = 有项目 − 无项目"小图 |
| S44d | L94 后半（~54 字） | 五顶帽子缩略（复用 A11）+ 两组易混词三行对照 |
| S44e | L95（43 字） | 第四关放大：可研基础上 → 第三方 → 三性 → 红条"没有《项目章程》" |
