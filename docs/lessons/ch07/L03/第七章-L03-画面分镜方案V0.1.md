### 2.9 倒计时规范（本课新增，硬规则）

**目的**：把"读完题干"和"开始解析"之间拉开 3 秒，让学生先自己想。

#### 结构

| 要素 | 规格 |
| :--- | :--- |
| 时长 | **90 帧（3.0 秒）**，从读完题干的最后一字算起 |
| 音频 | 该 3 秒内**无人声**（IR 的 `pauseDirectives` 插入 3000ms 静音） |
| 视觉 | 题卡保留在屏上，选项压暗到 0.35；中央叠加倒计时环 + 数字 3→2→1；环下方一行小字「想一想：这道题选什么？」 |
| 环 | 复用 `ExamQuizCard` 的 `thinking-pause` 实现（上限 90 帧正好 3 秒） |
| 结束 | 数字归 0 的同时，判卷开始（第一个 `eliminate-option` cue 落在第 90 帧之后） |

#### 七处倒计时（含合并规则）

| # | 题 | 读完题干的行 | 停顿起点（锚句末尾） | 说明 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | 24上1 T17 | L20 | "问描述正确的是：" | 左侧题 |
| 2 | 24上2 T19 | L26 | "问描述不正确的是：" | 右侧题，与 #1 同块但不合并（两题分别读） |
| 3 | T18 + 23下3 T23 | L64 | "…评价、分析和论证？" | **两问合并一次**（同一考点：铁三角） |
| 4 | 25上1 T33 | L65 | "…可靠性、横线？" | 独立题 |
| 5 | 23年5月 T22 | L68 | "选哪个？" | 独立题 |
| 6 | 23下1 T46 + 23下4 T23 | L69 | "哪一项不属于项目评估的依据？" | **两问合并一次**（同一考点：评估依据） |
| 7 | 26上1 T27 | L87 | 念完 A/B/C 三个选项之后 | 题干在 L85、选项在 L87，停顿放在选项念完之后 |

> **不设倒计时**：23下2 T14（L27 顺带一提）、23下4 T23 的"挖空"细节（在 #6 的范围里）。

#### 几何（按 L01 实现，已实测）

- 环位于**题卡右上角**（真题标签同一行右侧），直径约 76px——这是 L01 已验证的位置与尺寸，本课沿用；
- 环内数字 26 号、金色；环左侧一行 18 号小字「先自己选」；
- 选项**不压暗**——L01 的 `thinking-pause` 只画环，实测保持原亮度；如要压暗需改公共模板，本次不动（避免改变 L01 已验收的画面）。
- **不居中**：居中会遮住题干，且与 L01 的视觉语言不一致。

## 五、关键镜头详设

### 5.1 S07 / S10 / S26 / S29 / S32 / S35 / S42 · 倒计时镜（本课主角）

- **布局**：题卡保持在原位不动；选项区整体 `opacity 0.35`；环叠在题卡右上角（真题标签右侧），不遮挡题干。
- **环**：复用 `ExamQuizCard` 的 `thinking-pause`——环从 0 走到 1，耗时 90 帧；环内数字 `ceil(剩余秒)`，3 → 2 → 1。
- **小字**：环下 150px，22 号、`text2` 色，每镜文案不同（见分镜表"画面"列），提示"这一题要想什么"。
- **音频**：这 3 秒必须**真静音**；由 IR 的 `pauseDirectives` 在该句末尾插入 3000ms，TTS 不读任何字。
- **节奏**：数字归 0 的下一帧，第一个判卷动作开始——学生不会觉得"卡住"。

### 5.2 S06–S11 · 左右双题

- **布局**：左卡 `x=96 w=830`，右卡 `x=974 w=830`；两卡同一 `top=300`。
- **压暗规则**：讲左题时右卡 0.55，讲右题时左卡 0.55——用明度提示"现在看哪边"。
- **倒计时**：两次，各自在读完该题题干之后；这就是"双题同屏"与"每题一停"的折中。

### 5.3 S16 · 精度阶梯（复用 `kit/Scale`）

- **刻度**：`at` 0.08 / 0.38 / 0.68 / 0.94，标注 `毛估 ±30%` `初可研 ±20%` `详可研 ±10%` `设计开发 ±5%`。
- **强调**：初可研与详可研两枚用金色（本课两块知识的颜色），另两枚中性。
- **动态**：四刻度逐个亮起，`fill` 从 0.08 推进到 0.94，表达"越往后越准"。

### 5.4 S21 · 铁三角

- **布局**：等腰三角，顶点在 `(960, 300)`，底边两点 `(560, 640)`、`(1360, 640)`。
- **三块内容**：基础（可行性研究）/ 主体（第三方）/ 目的（可靠·真实·客观）。
- **警示**：每块下方一行红字——「不是立项申请」「不是建设单位」「不是只看安全性」。
- **动效**：三角连线 0.6 s 描绘，三块随线到位。

### 5.5 S43 · 嫁接型陷阱拆解

- **布局**：D 选项原文置顶；下方两栏「建设必要性评估」「安装工程标准评估」。
- **动作**：D 的原句被切成两段，前半飞入左栏（绿描边），后半飞入右栏（红描边）；中间留一条虚线表示"被缝合过"。
- **收口**：底部一行「命题人把两个评估项嫁接在了一起」。

## 八、独立判断说明与风险

### 8.1 五条设计取舍

1. **② 门拆成 ②a/②b 两个台阶**。L02 结尾把四关讲成"提申请 / 做可研 / 拍板"，本课要讲"可研还要分两步"，所以在轨道上直接把第二关拆成台阶——不新画一张图，学生不用重建坐标。
2. **倒计时独立成镜，不与判卷同屏**。如果把环叠在判卷过程里，视觉上会"又转又划"，注意力分裂；独立成镜、静音 3 秒，才是真的给思考时间。
3. **双题（T17/T19）各停一次，而不是合并**。因为口播是分开读题的（L20、L26），合并会造成"读完左边就想往下走"的断裂。
4. **T18+T23、T46+23下4 T23 各合并一次**。这两组是"同一考点两问"，且口播在同一句里连着读完，合并才符合听觉节奏。
5. **S17 财务常识灰化处理**。口播自己说"顺带记住"，画面就不该给它和第二考点同等的权重——这是"画面服从语气"。

### 8.2 风险与处理

| # | 风险 | 影响 | 处理 |
| :---: | :--- | :--- | :--- |
| R1 | 全片 18:40，比 L02 还长 | 注意力 | 讲稿已经压缩过（3961 字），若实测超 20 分钟，优先砍 S17（财务常识）与 S19（表 7-1） |
| R2 | 7 处停顿会打断节奏 | 观感 | 每处只有 3 秒且有环提示；若实测觉得碎，可把 S29（T33）与 S32（T22）各减到 2 秒 |
| R3 | 段 4 有 8 个连续知识镜（S12–S19） | 信息密度高 | 用 A24 四考点导航常驻顶部，让学生始终知道"现在讲第几条" |
