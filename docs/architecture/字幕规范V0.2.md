# 字幕规范 V0.2

更新日期：2026-11-02。适用于各课时的口播字幕与独立 SRT。

本规范负责字幕文字、切分、时间与导出格式。外观统一见[视频画面规范](视频画面规范V0.2.md)第六节，音频与教学停顿见[音频规范](音频规范V0.2.md)。现有方法入口查[公共能力索引](公共能力索引V0.1.md)第七节。

## 一、内容与数据来源

字幕对应已确认口播稿，保留文字与标点，只做分条，不增删词语、不做同义改写，也不混入画面文案或制作指令。

使用同一版本口播、实际配音与对齐数据生成字幕。视频口播字幕与 SRT 从同一份字幕数据导出；完整课时和短样段分别使用对应时间轴。

## 二、切分规则

优先在标点和完整语义处断开，尊重句末停顿，不为凑字数跨句拼长行。右引号、右括号跟随前面的句子，避免下一条以收尾符号开头。

沿用当前按原文标点切分的参数：

| 项目 | 基准 |
| --- | --- |
| 强断点 | 句末 `。！？…`，累计可见字达到 `4` 时分条 |
| 弱断点 | `，、；：`，累计可见字达到 `10` 时分条 |
| 聚合阈值 | 累计可见字达到 `26` 时结束当前条目 |
| 长条目二次切分 | 超过 `28` 个可见字时，依次在 `：；`、`，`、`、—` 中选择靠近中点的断点 |
| 最短条目时长 | `120 ms`，是时间有效性下限，不代表实际可读性已经通过 |

这里的可见字计数沿用当前实现的汉字、英文字母和数字口径，不含标点。聚合阈值不是单行几何容量，也不保证每条自动小于该值。

找不到合法断点的长条目保留完整文本，结合实际显示处理分条；不得删字、擅自改稿或缩小字幕字号。现有函数可能过滤很短的条目、对缺失对齐使用兜底时间；因此仍需核对短句与原文覆盖，不能把函数成功返回当作内容完整或对齐正确。

## 三、时间规则

| 项目 | 要求 |
| --- | --- |
| 起止 | 依据对应实际音频的首末 token 时间及组装偏移确定，不用独立估计的帧号 |
| 顺序 | 起止有效、时间递增、相邻条目不重叠，落在对应片段或整课范围内 |
| 首尾 | 首条随实际发音开始，不强制归零；末条随实际发音结束，不套用固定片尾偏移 |
| 组装 | 区分段内局部时间与整课时间，字幕和画面采用同一组偏移，不重复加偏移 |
| 短样段 | 按实际裁切起点归零，并裁到样段范围内；不得直接将样段字幕作为整课交付 |
| 重新配音或修改停顿 | 更新受影响的字幕、倒计时和画面揭示时序 |

现有超长条目切分可能按字数比例拆分时间，不能据此认定每个断点都与发音精确对应。出现明显不同步或找不到对应词句时，在受影响片段中依据实际音频与对齐数据处理。

## 四、思考停顿与版本

思考停顿的位置、时长、倒计时和答案揭示统一按音频规范第五节执行。字幕在整个静音窗口内为空，不能延续上一句或提前显示解析。

**检查字幕条目的起止是否跨越静音窗口；“窗口内没有 token”不能保证字幕已经清空。** 视频字幕与 SRT 都需使用处理后的同一份数据。

无声无口播字幕版不显示口播字幕，保留画面中的教学文字。两者的呈现边界见视频画面规范。

## 五、SRT 格式

| 项目 | 规定 |
| --- | --- |
| 编码 | UTF-8，无 BOM |
| 编号 | 从 `1` 连续递增，导出时重排 |
| 时间 | `HH:MM:SS,mmm --> HH:MM:SS,mmm`，毫秒使用逗号分隔 |
| 块结构 | 编号行、时间行、文本行、空行 |
| 内容与版本 | 与成片口播字幕同源、同版；最后一条不超过对应视频结束点 |

交付位置与文件命名沿用[AI互动流程总结](AI互动流程总结V0.1.md)及本课现有约定，不另建字幕交付目录。

## 六、检查与修订

在原有预览与交付节点检查本次新增或受影响的字幕，同版有效检查结果直接沿用：

- 与口播稿的文字、标点及顺序一致，无漏句或重复。
- 无收尾引号、括号孤立到下一条，无零时长、重叠或明显错位。
- 实际显示符合视频画面规范，读题和思考阶段不泄露答案。
- 字幕不覆盖思考静音，SRT 与成片使用同版数据和正确的时间轴。

统计信息可用于定位异常，不把旧课的条数、平均字数、标点比例或平均时长当作所有课程的验收阈值。变更后只更新和复核受影响的字幕、预览与导出文件；未改配音时复用原音频。
