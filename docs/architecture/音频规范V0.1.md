本规范规定课程音频的制作与验收要求。新制作和后续修订按本规范执行；文档建立不代表现有脚本、音频和成片已经全部符合要求。既有成果的适配随具体制作任务安排，不因发布规范自动重做。

## 一、基本原则

1. **口播稿决定内容。** 配音以确认的口播稿为准，切段不擅自改写，不能漏读、重复或添加原稿没有的内容。
2. **实际音频决定时序。** 字幕、讲解重点的揭示、倒计时和整课时长，依据实际音频、对齐结果及组装偏移确定。
3. **整课使用连续口播轨。** 分段制作，整课组装为一条连续音轨；本版不混入音乐、音效或多人对白。
4. **教学停顿是真实静音。** 停顿写入音频，并同步更新字幕和画面时间，不能只延长画面停留。
5. **字幕同源。** 视频口播字幕与独立 SRT 使用同一版本的字幕数据。
6. **音量整轨统一处理。** 只在整轨完成后做一次峰值归一化，不按句、按段分别拉响度。

画面和字幕呈现遵循 [README 列出的项目展示规范](../../README.md)，本文件只规定音频内容、格式和同步关系。

## 二、口播稿与切段

| 项目 | 要求 |
| :--- | :--- |
| 内容来源 | 使用已确认的口播稿版本，保留段落与原稿的对应关系，便于定位修复 |
| 切分方式 | 按句或语义完整的分句切分，优先选择标点处，避免截断术语、数字或英文表达 |
| 文本一致性 | 只切分，不增删字词、不做同义改写；错读、多音字、数字或英文读法问题需结合原稿修复并试听 |
| 单段长度 | 遵守实际使用的 TTS 引擎与脚本限制，兼顾语义完整和生成稳定性 |
| 停顿指令 | 与朗读正文分开记录；“停顿 3 秒”等制作指令不送入 TTS 朗读 |
| 版本与复用 | 沿用已有素材和缓存管理方式；文本、音色及生成配置未变时可复用已确认素材，修复时保留旧版本 |

分段 WAV 是制作素材，不能替代整课 WAV 交付。先通过有声音的小样确认音色、语速、发音和停顿，再沿用到后续段落。

## 三、采样率、声道与编码

### 3.1 统一规格

| 环节 | 采样率 | 声道 | 编码 / 位深 |
| :--- | :--- | :--- | :--- |
| TTS 分段原件 | **24000 Hz** | 允许单声道（mono） | WAV / PCM16 |
| 整轨 WAV | **24000 Hz** | **双声道（stereo）** | WAV / PCM16 |
| 预览和渲染使用的整轨音频 | **24000 Hz** | **双声道** | 与整轨 WAV 同一版本 |
| 有声 MP4 音轨 | **48000 Hz** | **双声道** | AAC |
| 无声无口播字幕版 MP4 | 不适用 | **无音轨** | 不附带静音音轨 |

制作与整轨装配保留 24 kHz；最终导出 MP4 时转换为 48 kHz，避免中间步骤来回重采样。采样率转换不改变播放速度、音高或时间轴，也不作为提升原始配音细节的手段。

### 3.2 双声道处理

- 单声道源信号等幅复制到左右声道，整轨 WAV 的 **L、R 逐样本一致**。
- 转换时保持每个声道的信号幅度，不依赖会改变音量的默认升混行为。
- 已经是符合要求的双声道素材，保持其声道与幅度，不重复转换或叠加。
- 成片复核双声道、音量和实际听感；双声道标记不能代替音量检查。

## 四、对齐与时间轴

使用实际 WAV 与对应口播文本进行强制对齐。当前项目使用的 Qwen3-TTS、Qwen3-ForcedAligner 及其环境位置见 [README](../../README.md)；适合 GPU 的生成和对齐工作优先使用 RTX 5060 Ti 16GB。遇到设备、权限或环境障碍，及时说明原因和所需操作。

| 项目 | 要求 |
| :--- | :--- |
| 对齐对象 | 对齐文本必须对应实际播放的同一版本音频 |
| 内容覆盖 | 核对 token 文本对原稿朗读内容的覆盖和顺序；不能只比较 token 数量来判断是否完整 |
| 时间有效性 | 起止时间有效，顺序正确，并落在对应音频范围内 |
| 坐标说明 | 明确时间是段内局部时间还是整课全局时间；局部时间组装时加偏移，已是全局时间的不重复加偏移 |
| 画面锚点 | 从对齐词句、停顿记录或已有音频组装数据派生，不凭估计填写独立的秒数或帧号 |
| 异常处理 | 出现漏字、错位、无效时间或找不到讲解锚点时，定位并修复，不用估算时刻掩盖问题 |

沿用当前课时已有的 `audio-timeline.json`、字幕及组装数据。可使用现有的 `pauseDirectives`、题目时间记录或组装偏移表达停顿，不要求所有课时新增同一种文件结构或锚点函数。

## 五、读题后的 3 秒思考停顿

**口播完成题干朗读后、解析开始前，插入完整 3 秒真实静音。如果口播还要朗读选项，则在题干和需要朗读的选项全部结束后插入；不朗读选项时，放在题干读完之后。**

进入停顿时，画面应已提供题干和可供判断的选项，让学生获得完整信息后思考。用户另有明确安排时，按其要求执行。

| 项目 | 要求 |
| :--- | :--- |
| 时长 | **3000 ms**；按采样数插入完整静音，不以约 3 秒的画面停留替代 |
| 音频内容 | 整个窗口内没有口播；原始 PCM 中插入零值样本，不用压低音量或淡出来代替 |
| 插入位置 | 读题结束、发音完整保留之后，解析开始之前；不得切掉句尾发音 |
| 制作指令 | 停顿要求记入课时音频制作数据，不朗读“停顿三秒”等提示 |
| 倒计时 | 与音频静音窗口同步显示 `3→2→1` |
| 口播字幕 | 停顿期间清空，不延续上一句，也不提前显示解析字幕 |
| 教学画面 | 保留题面；读题及思考阶段无答案、解析、勾叉或暗示答案的选项颜色 |
| 后续时序 | 停顿后的配音、字幕、画面揭示同步顺延；解析和答案按后续讲解出现 |

停顿位置和时长应能从实际音频与课时数据中核对。对已经包含思考静音的素材，不在组装时再叠加一次 3 秒。

## 六、整轨装配与音量处理

### 6.1 拼接与收尾

- 按已确认的讲解顺序拼接，保持分段内容完整，不让相邻口播重叠，不交叉淡化口播段。
- 普通句间、段间停顿按语义、标点和已确认的听感安排，已有自然静音应计入衔接判断。
- 可以沿用当前流程的首尾静音整理，但不得截断发音或造成突兀衔接。
- 组装产生的静音、帧边界补齐和内容段偏移，都计入最终时间轴。
- 片尾停留按当前课时已确认的安排处理；音频和画面不能因重复补尾或截短而失去对应。

### 6.2 峰值归一化

| 项目 | 规定 |
| :--- | :--- |
| 目标峰值 | 整轨 WAV **−1.0 dBFS** |
| 验收范围 | **−1.0 ±0.1 dBFS** |
| 正增益上限 | **+4.0 dB** |
| 处理粒度 | 整轨装配完成后统一一次，左右声道使用相同增益 |
| 段级处理 | 不对每句、每段单独做峰值归一化，不随内容自动拉响度 |
| 压缩与限幅 | 不使用自动动态压缩或砖墙限幅来强行满足指标 |
| 削波 | 处理后的 PCM 不得出现削波 |
| 平均音量 | 可记录作为排查依据，不规定统一的平均音量或 LUFS 目标 |

若达到 −1.0 dBFS 需要超过 +4.0 dB 的增益，应回到源配音排查并修复或重新生成，再装配验收；不能突破增益上限，也不能只加到上限就宣称达到峰值标准。

峰值达标仍需检查句间音量和听感。某段明显偏轻、偏响或失真时，定位源素材处理，不靠提高整课音量掩盖局部问题。保留未做整轨归一化的源素材，修订后从源素材重新装配，避免累积处理。

### 6.3 成片音轨

成片使用已确认的整轨 WAV，只在最终导出时进行 48 kHz 转换和 AAC 编码，不在播放组件或导出环节再次归一化、淡入淡出或压限。

**−1.0 ±0.1 dBFS 的验收对象是整轨 PCM WAV。** AAC 编码后的解码波形可能存在峰值差异，需复核有无削波、失真和非预期音量变化，不要求有损编码后的样本与 WAV 完全一致。

无声版最终文件必须没有音轨；将播放音量设为零不等同于无音轨交付。

## 七、字幕与画面同步

字幕切分、字数、排版和 SRT 格式以 [字幕规范 V0.1](字幕规范V0.1.md) 为准，本规范不另设字幕长度阈值。

1. 视频口播字幕与 SRT 从同一份字幕数据导出，文本对应确认的口播稿，只断句，不改写。
2. 字幕时间由对应音频 token 与组装偏移确定，起止有效、顺序正确、不重叠。
3. 教学静音窗口不得与口播字幕重叠；不能仅凭“没有 token”推断字幕已正确清空，应检查跨越停顿的字幕条目。
4. 分段组装后，字幕和画面锚点使用同一组偏移；整课 SRT 使用整课时间，短样段裁切后按样段起点归零。
5. 配音时长或停顿变化后，更新受影响的字幕、倒计时及画面揭示时间。

## 八、文件组织与交付

沿用当前项目按课时、内容段划分目录的方式：

| 位置 | 用途 |
| :--- | :--- |
| `workspaces/<工作区标识>/` | 原始分段音频、对齐结果、时间轴、字幕、组装数据及整轨音频 |
| `public/audio/<工作区标识>/` | 预览与渲染使用的音频，按组件实际引用的相对路径放置 |
| `deliverables/<lessonId>/` | 整课 WAV、SRT、有声 MP4 和无声无口播字幕 MP4 |

工作区标识可以包含内容段或整课后缀，沿用课时现有命名，不为套用示例批量改名。常用整课交付文件名为：

```text
<lessonId>-full.wav
<lessonId>.srt
<lessonId>-voiced-captioned.mp4
<lessonId>-silent-clean.mp4
```

使用项目内相对路径引用播放素材。重新生成或替换前，检查旧音频是否仍被其他预览或已确认版本引用；交付物不静默覆盖。音频与成片按 [README](../../README.md) 的媒体保存约定另行备份。

## 九、质量检查与试听

### 9.1 技术检查

| 检查项 | 通过要求 |
| :--- | :--- |
| 朗读内容 | 与确认的口播稿对应，无漏读、重复、错读或额外内容 |
| 整轨 WAV | 24 kHz、双声道、PCM16，左右声道逐样本一致 |
| 峰值与增益 | 峰值 −1.0 ±0.1 dBFS，正增益不超过 +4.0 dB，无削波 |
| 有声 MP4 | 一条 48 kHz、双声道 AAC 音轨 |
| 无声版 MP4 | 音轨数为 0，无底部口播字幕，保留教学内容 |
| 思考停顿 | 数量与本课约定的位置一致，每处写入 3000 ms；测量允许误差 ±10 ms |
| 停顿内容 | 原始 PCM 静音窗口为零值；期间无口播字幕，倒计时同步且不泄露答案 |
| 整轨时长 | 与包含组装补齐和片尾安排的最终音频时间数据一致，误差不超过 10 ms |
| 字幕 | 视频字幕与 SRT 同源、同版；整课 SRT 末条不超出视频结束点 |
| 音画同步 | 检查起点、段落交界和结尾，配音未被截断、重复或整体错移 |

可沿用现有工具检查：`ffprobe` 核对格式、声道、采样率、流起点和时长；FFmpeg 检查音量与静音，结合 PCM 样本及时间数据核对精确停顿。低于某个检测阈值只能说明“足够安静”，不能单独证明已写入零值静音。

AAC 编码延迟或尾部补齐应与内容错位分别核对，不仅凭容器总时长判断同步，也不照搬某课的固定尾差作为通用豁免。

### 9.2 试听与审核

沿用“小样确认 → 分段制作和审核 → 整课组装交付”的节点，不新增逐条审批。重点试听：

- 音色和语速是否适合持续听课，术语、数字和英文是否读对。
- 是否存在漏字、重复、失真、杂音、截字或突兀的换气与拼接。
- 段落交界音量是否稳定，整轨 WAV 与成片有无非预期的音量差异。
- 读题后是否确有完整的 3 秒思考时间，字幕、倒计时与后续解析是否同步。

技术检查结果与人工视听结论分别记录。工具检查通过、文件已生成，均不等于用户已经通过听感与整课审核。

## 十、变更与回归

| 改动 | 需要更新或复核的内容 |
| :--- | :--- |
| 修改口播或重新生成配音 | 受影响的 TTS、对齐、装配、字幕和画面锚点；下游整课偏移随实际时长更新 |
| 修改教学停顿 | 音频静音、时间轴、后续字幕、倒计时与画面揭示；保留未变化的口播素材 |
| 修改字幕切分 | 更新同源字幕与 SRT，复核停顿窗口和成片字幕 |
| 只改画面 | 保留音频数据，复核与口播、字幕的对应关系 |
| 仅处理整轨音量或声道 | 从源素材处理，复核峰值、增益、声道及听感；时长未变时不凭空重估时间轴 |
| 修改输出采样率或编码 | 复核格式、时长、起点及音画同步，不改变原有播放速度和音高 |

更新受影响的预览、成片和交付文件；无关课时与已确认版本保持原状。不得只替换新 WAV，却继续沿用已不匹配的字幕和画面时间。

## 十一、与现有实现的关系

当前项目已有单声道整轨、保留源采样率的成片导出，以及按内容段独立组装的实现。后续按本规范制作或修订时，应落实双声道整轨、48 kHz 成片与统一音量处理，再核对实际产物。

本规范不要求统一重写制作管线，也不依赖某一课时专用脚本。当前流程入口见 [README](../../README.md)；本版仅建立规范，尚未据此修改脚本或重新处理既有媒体。
