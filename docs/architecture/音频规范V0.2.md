# 音频规范 V0.2

更新日期：2026-11-02。适用于课程配音、整轨 WAV、有声成片音轨及教学停顿。

本规范负责音频内容、格式、音量和统一时间轴；字幕文字与 SRT 见[字幕规范](字幕规范V0.2.md)，画面与字幕外观见[视频画面规范](视频画面规范V0.2.md)。制作步骤、GPU 分工和交付目录按[AI互动流程总结](AI互动流程总结V0.1.md)，方法与命令查[公共能力索引](公共能力索引V0.1.md)。

## 一、基本原则

- 以确认的口播稿为准，不漏读、重复、改写或添加内容。
- 字幕、倒计时、画面揭示和整课时长依据实际音频、对齐结果及组装偏移确定。
- 分段制作，整课装配为一条连续口播轨；本版不混入音乐、音效或多人对白。
- 教学停顿写入音频；整轨装配完成后统一处理音量，不按句、按段分别拉响度。

## 二、口播稿与切段

按句或语义完整的分句切分，优先选标点处，避免截断术语、数字和英文表达。单段长度遵守实际 TTS 引擎与脚本限制，不套用旧课字数上限。

保留分段与原稿的对应关系。停顿等制作指令与朗读正文分开记录，不送入 TTS。错读、多音字、数字和英文读法需结合原稿修复并试听。

在已有小样节点确认音色、语速、发音与停顿，后续沿用。文本、音色和生成配置未变时复用已确认素材；修复时保留旧版本。分段 WAV 不能替代整课 WAV 交付。

## 三、采样率、声道与编码

| 环节 | 采样率 | 声道 | 编码 |
| --- | --- | --- | --- |
| TTS 分段原件 | `24000 Hz` | 允许单声道 | WAV / PCM16 |
| 整轨 WAV，包括预览与渲染使用的整轨 | `24000 Hz` | 双声道 | WAV / PCM16 |
| 有声 MP4 音轨 | `48000 Hz` | 双声道 | AAC |
| 无声无口播字幕 MP4 | 不适用 | 无音轨 | 不附带静音音轨 |

制作阶段保留 24 kHz，最终导出 MP4 时转换为 48 kHz，避免中间来回重采样。转换不得改变播放速度、音高或时间轴。

单声道源等幅复制到左右声道，整轨 WAV 的 **L、R 逐样本一致**，每个声道保持原信号幅度。符合要求的双声道素材不重复升混或叠加；复核声道与听感，不能只看双声道标记。

## 四、对齐与时间轴

使用实际播放版本的 WAV 与对应口播文本进行强制对齐。核对 token 文本的覆盖、顺序与时间范围，不仅比较数量。漏字、无效时间或找不到讲解锚点时，定位受影响片段处理，不用估算时刻掩盖问题。

明确段内局部时间与整课全局时间：组装时统一加偏移，已经是全局时间的不重复加。画面锚点从对齐词句、停顿记录或已有组装数据派生。

沿用本课现有时间轴和组装方式，可用 `pauseDirectives`、题目时间记录或组装偏移表达停顿，不要求每课新增同一种文件或锚点函数。

## 五、读题后的 3 秒思考停顿

题干读完后、首次正误判断或解析前，保留完整 **3 秒真实静音**。需要朗读选项时，在题干和这些选项读完后安排；不朗读选项时，在题干读完后安排。进入停顿时，中性题面和可供判断的选项应完整可读。

题目长短不改变这 3 秒，学生可自行暂停阅读；用户另有明确安排时按其要求执行。

| 项目 | 要求 |
| --- | --- |
| 音频 | 插入 `3000 ms` 零值 PCM 样本，不截断句尾，不以压低音量、淡出或画面停留代替 |
| 倒计时 | 与静音窗口同步显示 `3→2→1` |
| 口播字幕 | 全窗口为空；字幕区间的检查方式见字幕规范第四节 |
| 题面与揭示 | 保留题面；读题与思考阶段无答案、解析、勾叉或暗示答案的选项颜色 |
| 后续时序 | 配音、字幕、画面揭示同步顺延，答案按后续讲解出现 |

停顿位置和时长必须能从实际音频及课时数据中核对。素材已经包含该段思考静音时，不在组装时再插入一次。

## 六、整轨装配与音量处理

按讲解顺序拼接，保留完整发音，不让相邻口播重叠，不交叉淡化口播段。普通句间、段间停顿沿用语义、标点和已确认听感，已有自然静音计入衔接判断。

首尾静音整理不得截字；组装静音、帧边界补齐和片尾停留都计入最终时间轴，不重复补尾或截短。

| 音量项目 | 规定 |
| --- | --- |
| 整轨 WAV 目标峰值 | **−1.0 dBFS**，验收范围 **−1.0 ±0.1 dBFS** |
| 正增益上限 | **+4.0 dB** |
| 处理次数 | 整轨装配完成后统一一次，左右声道使用相同增益 |
| 段级与动态处理 | 不按句或按段归一化，不使用自动动态压缩或砖墙限幅强行满足指标 |
| 削波 | 处理后的 PCM 不得削波 |
| 平均音量 | 可用于排查，不设置统一平均音量或 LUFS 目标 |

达到目标需要超过增益上限时，回到源配音排查、修复或重新生成，不能突破上限或只加到上限就宣称达标。局部偏轻、偏响、失真同样定位源素材处理。保留未经整轨归一化的源素材，修订后重新装配，避免累积处理。

成片使用同版整轨 WAV，只做最终采样率转换和 AAC 编码，播放与导出环节不再次归一化、淡入淡出或压限。峰值验收对象为 PCM WAV；AAC 解码后复核削波、失真和非预期音量变化，不要求有损编码后的样本与 WAV 完全一致。无声版必须没有音轨，不能仅将音量设为零。

## 七、检查与修订

在原有预览与交付节点检查本次相关内容：

| 检查项 | 通过要求 |
| --- | --- |
| 朗读 | 与口播对应，无漏读、重复、错读、额外内容或截断发音 |
| 格式与音量 | 符合第三、六节；有声 MP4 只有一条对应的音轨，无声版音轨数为零 |
| 思考停顿 | 位置、数量正确，原始 PCM 窗口为零值；按第五节写入，测量误差不超过 `±10 ms` |
| 整轨时长 | 与包含组装补齐和片尾安排的最终音频时间数据一致，误差不超过 `10 ms` |
| 同步 | 开头、段落交界、停顿、结尾对应；字幕、倒计时和答案揭示使用同一时间轴 |
| 听感 | 音色、语速、术语发音适合听课，段落间无突兀音量变化、杂音或失真 |

沿用 `ffprobe`、FFmpeg 和 PCM 样本核对工具。音量低于检测阈值不能单独证明零值静音；AAC 编码延迟或尾部补齐也不能仅靠容器总时长判断，应核对实际流起点与内容同步。

配音或停顿时长变化后，更新受影响的对齐、字幕、倒计时、画面锚点及下游组装偏移；只改声道或音量且时长未变时，不重新估算时间轴。只改画面时复用音频。

技术检查与用户试听结论分别记录，沿用既有审核节点。规范存在不代表所有历史脚本和媒体已经符合要求；在本次制作或修订范围内适配并核验，不自动重做旧课或改造整条管线。
