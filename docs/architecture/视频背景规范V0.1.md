## 一、明确指定使用的背景

**课程视频统一使用现有 `TechNetwork` 科技网络背景，类型标识为 `tech-network`。**

| 项目 | 指定实现 |
| :--- | :--- |
| 背景组件 | [`src/visual/backgrounds/tech-network/TechNetwork.tsx`](../../src/visual/backgrounds/tech-network/TechNetwork.tsx) 导出的 `TechNetwork` |
| 参数定义 | [`src/visual/backgrounds/tech-network/schema.ts`](../../src/visual/backgrounds/tech-network/schema.ts) 导出的 `techNetworkSchema` |
| 已审核用法参考 | [`src/lessons/ch06/L01OpeningPreview.tsx`](../../src/lessons/ch06/L01OpeningPreview.tsx) 中的 `bg` 配置及 `<TechNetwork {...bg} />` |

视觉特征为深蓝渐变底、低对比度网格、缓慢运动的节点连线及细微颗粒。背景作为教学内容的衬底，不承担题目答案、进度提示或其他教学信息。

直接复用该组件，不用“类似的科技背景”替代，不重新仿写一套背景，也不用成片截图替代动态背景。克隆项目使用自身仓库内相同相对路径的组件，不跨目录导入原项目源码。

## 二、后续制作的基准参数

沿用 L01 开场的配置：

```tsx
const background = techNetworkSchema.parse({
  type: "tech-network",
  ganttEnabled: false,
  linkOpacity: 0.035,
  nodeOpacity: 0.06,
  highlightCoreOpacity: 0.1,
  highlightGlowOpacity: 0.06,
});

// 在教学内容下方渲染背景。
<TechNetwork {...background} />
```

未列出的参数使用 `techNetworkSchema` 现有默认值，不自行增加覆盖项。其中底色为中心 `#0B1A33`、边缘 `#060E1F`，循环周期为 30 秒。`ganttEnabled: false` 关闭背景自带的甘特条，避免与课程内容及字幕区域混淆。

不要只传入 `{ type: "tech-network" }` 来代替上述配置：Schema 默认开启甘特条，节点、连线和部分高亮的透明度也与本基准不同。

L01 已审核的不同段落存在少量参数差异。本规范将开场配置作为后续制作基准，不要求回改既有段落或重新导出旧成片。

## 三、叠放与使用要求

1. 背景覆盖整个画幅，位于教学内容、头部导航和口播字幕下方。每个可见画面使用一层背景，避免母版和内容组件重复叠加。
2. 保留组件现有的动画与纹理实现，不额外叠加闪烁、强光、粒子或装饰文字。
3. 内容区可以按讲解安排图形、题目和半透明卡片；局部内容面板不改变整屏背景的选用。
4. 需要改变背景类型、动画或本基准参数时，先说明原因并给用户看小样，再应用到后续制作；不要直接修改公共背景组件来解决某一课的局部布局问题。

## 四、检查重点

- 使用的确实是 `TechNetwork` / `tech-network`，配置与本规范一致。
- 甘特条已关闭，背景没有重复叠加，正文和字幕清晰可读。
- 同时查看静止画面与播放效果，确认背景运动不干扰阅读；工具检查不能替代用户的画面审核。
