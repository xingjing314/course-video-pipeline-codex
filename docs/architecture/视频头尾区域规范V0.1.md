## 一、画幅的三段划分

画幅固定 **1920 × 1080 @ 30fps**。垂直方向切成三段，**互不侵占**：

```
 y=0     ┌────────────────────────────────────────────┐
         │ ① 头部导航条   y 14 – 46（高 32）           │  HeaderBreadcrumb
 y=48    ├────────────────────────────────────────────┤
         │ ② 标题区       y 48 – 约 200                │  SceneShell 的 eyebrow + title + subtitle
         │                                             │
         │ ③ 教学舞台     y 110 – 900                  │  章节组件 / 模板
         │   （1720 × 800 安全区）                      │
 y=941   ├────────────────────────────────────────────┤
         │ ④ 字幕槽       y 941 – 1046（1–2 行浮动）    │  CaptionsOverlay
 y=1080  └────────────────────────────────────────────┘
```

| 区域 | 垂直范围 | 水平范围 | 谁负责 |
| :--- | :--- | :--- | :--- |
| ① 头部导航 | `top: 14`，高 32 | `left/right: 96` | `HeaderBreadcrumb`（或章节自画） |
| ② 标题区 | `top: 48` 起 | `left/right: 96` | `SceneShell` |
| ③ 教学舞台 | **110 – 900** | 96 – 1824（≈1720 宽） | 各段组件 |
| ④ 字幕槽 | `bottom: 34`，高 66（1 行）/ 105（2 行） | `left/right: 160`，盒内 `maxWidth: 1520` | `CaptionsOverlay` |

> **硬边界**：舞台内容 `y + 高度 ≤ 900`。字幕盒顶部在 1 行时是 **980**、2 行时是 **941**——900 到 941 之间只有 41px 余量，没有第二次机会。

## 二、头部（HeaderBreadcrumb）

### 2.1 结构与内容

一条 32px 高的横条，左右两端对齐：

```
┌─ 左端 ────────────────────────────┐        ┌─ 右端 ──────────────────────┐
│ [CH07-L03]  第 7 章 项目立项管理 · L03 │        │ 章末总图与交棒   [S44c · 37/43] │
└──────────────────────────────────┘        └────────────────────────────┘
```

| 元素 | 内容 | 来源 |
| :--- | :--- | :--- |
| 课程码（左，胶囊） | `lessonId.toUpperCase()` → `CH07-L03` | `lesson.lessonId` |
| 课程名（左，文字） | `第 7 章 项目立项管理 · L03` | `lesson.lessonTitle`（会剥掉"（讲师口播与画面分镜合一稿…）"后缀） |
| 段落名（右，文字） | 如 `章末总图与交棒` | `scene.segmentTitle` |
| 进度（右，胶囊） | `S44c · 37/43` | `scene.id` + `order/total` |

### 2.2 样式参数（可直接照抄）

| 元素 | 字号 | 字重 | 颜色 | 其他 |
| :--- | ---: | ---: | :--- | :--- |
| 课程码 | 14 | 700 | cyan `#2EC4D6` | 底 `cyan α0.16`、描边 `1px cyan α0.45`、圆角 6、内边距 `2px 10px`、字距 1 |
| 课程名 | 15 | 500 | text2 `#8FB8D9` | 与课程码间距 12 |
| 段落名 | 14 | 400 | text2 `#8FB8D9` | 与进度胶囊间距 10 |
| 进度胶囊 | 14 | 700 | gold | 底 `gold α0.18`、描边 `1px gold α0.5`、圆角 999、内边距 `2px 10px` |

层级：`zIndex: 10`，`pointerEvents: none`（永不拦截交互）。

### 2.3 两种模式：`headerMode`

| 模式 | 谁画 header | 用在哪 |
| :--- | :--- | :--- |
| `scene`（默认） | `MasterCanvas` 按场景画，镜号 = 场景序号 | 一场一镜的课（L01、L02 多数段） |
| `chapter` | **章节组件自己画**，`MasterCanvas` 跳过 | 一个段覆盖多镜、镜号要在段内推进（L02/L03 的真题段） |

`chapter` 模式的实现约定：段组件内部再挂一次 `HeaderBreadcrumb`，把 `sceneOrder/totalScenes` 换成"章节内镜号 / 章节内总镜数"：

```tsx
// src/lessons/ch07/l03-spans.tsx
const { shot, order } = l03ShotAt(offset + frame);
<HeaderBreadcrumb sceneOrder={order} totalScenes={L03_SHOTS.length} ... />
```

**判定规则**：如果一个渲染段要跨越多个分镜（如"双题同屏"横跨 S06–S11），就必须用 `chapter`，否则顶栏镜号会停住不动。

### 2.4 与标题区的 14px 规则

顶栏下沿（y=46）到 `eyebrow` 首行之间保持 **14px** 视觉间隙——这是"导航"和"内容"的分界感来源。

实测基线（L02 §2.8）：顶栏字形底边距 24–38px，`eyebrow` 字顶 53–72px，差值稳定在 14px。改动任一侧字号时必须重测这条。

### 2.5 标题区（同属头部，但由 `SceneShell` 画）

| 元素 | 字号 | 颜色 | 约束 |
| :--- | ---: | :--- | :--- |
| `eyebrow` | 20 | text2 | 字距 3；**最多三级编号**（`7.3.1` ✅，`7.3.1-1` ❌） |
| `title` | 46 | text `#E6F1FA` | 字重 700、字距 1.2；建议 ≤ 22 字 |
| `subtitle` | 24 | text2 | `marginTop: 8`、`maxWidth: 1500`；建议 ≤ 40 字 |

## 三、尾部（CaptionsOverlay）

### 3.1 盒模型

```
bottom: 34
        ┌──────────────────────────────────────────┐
        │  padding 12 / 30                          │
        │      字幕文本  28px / 600 / 行高 1.4       │  ← maxWidth 1520，居中
        │  padding 12                               │
        └──────────────────────────────────────────┘
        圆角 14 · 描边 1.5px cyan α0.42 · 底 rgba(4,10,24,0.86) · 阴影 0 8px 28px
```

| 参数 | 值 |
| :--- | :--- |
| 定位 | `left: 160`、`right: 160`、`bottom: 34`，flex 居中 |
| 盒宽 | 内容自适应，上限 `1520` |
| 内边距 | `12px 30px` |
| 字号 / 字重 | 28 / 600 |
| 行高 | 1.4（单行 ≈ 39px） |
| 颜色 | text `#E6F1FA` |
| 底板 | `rgba(4,10,24,0.86)` + `1.5px` cyan 描边 + 投影 |
| 层级 | `zIndex: 20`（高于 header 与所有舞台内容） |

### 3.2 几何结果（改动前必算）

| 行数 | 盒高 | 盒顶 y | 与舞台底线（900）的距离 |
| :---: | ---: | ---: | ---: |
| 1 行 | 66 | **980** | 80 px |
| 2 行 | 105 | **941** | 41 px |
| 3 行 | 144 | 902 | **2 px —— 已经压线** |

**结论**：字幕最多 2 行。3 行时盒顶到 902，与舞台只差 2px，任何多出来的舞台元素都会相撞。

### 3.3 单条字幕的容量

- 盒内可用宽度 1520px，28px 字号 → **单行约 54 个汉字**；
- 实际数据：L03 共 266 条，平均 **16.4 字**，最长 **46 字**，79% 以标点结尾——都在单行内；
- 切分规则见 `src/pipeline/2-audio/srt-exporter.ts`：按标点切、遇到长句再切、**吸收收尾引号括号**（避免出现以 `”` 开头的字幕行）。

### 3.4 静音段没有字幕（不是特判）

倒计时 3 秒是 `pauseDirectives` 插进去的**真静音**，该区间没有 token，字幕自然为空。

这是设计选择：**思考时间不提供字幕**，避免学生用读字幕代替自己想。不需要在 `CaptionsOverlay` 里写任何"暂停隐藏"的逻辑。

### 3.5 两个版本的差异

| 版本 | 字幕 | 头部 |
| :--- | :---: | :--- |
| `L0xLesson`（有声带字幕） | ✅ | ✅ |
| `L0xLessonSilent`（无声纯净） | ❌ | ✅ |

头部是**教学文字结构的一部分**，两个版本都保留；只有口播字幕随 `includeCaptions` 开关。

## 五、常见错误

| # | 现象 | 原因 | 正确做法 |
| :---: | :--- | :--- | :--- |
| 1 | 卡片下半截被字幕压住 | 舞台元素 `y + 高度 > 900` | 写组件时先算 `y + height`，超过就缩高或上移 |
| 2 | 顶栏镜号不随画面推进 | 多镜段用了 `headerMode: "scene"` | 改 `chapter`，段内自画 header |
| 3 | 顶栏与标题"挤在一起" | 改了任一侧字号，14px 间隙被吃掉 | 重测 §2.4 的 14px 基线 |
| 4 | 字幕出现 3 行、压到舞台 | 单条字幕过长 | 在 `srt-exporter` 侧加切分，而不是缩字号 |
| 5 | 无声版里加了字幕 | `includeCaptions` 传错 | 无声版必须 `false` |
| 6 | 倒计时期间字幕还在 | 把暂停做成了"画面暂停"而非音频静音 | 停顿必须走 `pauseDirectives` |

## 六、改动影响面

| 改什么 | 影响 | 需要重渲染 |
| :--- | :--- | :---: |
| 顶栏字号 / 颜色 / 内容字段 | **全课所有镜头** | 是 |
| 顶栏高度 / `top` | 标题区与舞台的可用空间 | 是 |
| 标题区字号 | 舞台起点可能下移 | 是 |
| 字幕字号 / 内边距 | 字幕盒顶部位置（§3.2 表） | 是，且**所有已交付课程** |
| 字幕文本切分规则 | 字幕条数与断句 | 是（但不动音频） |

> 顶栏与字幕层属于**全局母版**，改动等于给所有课换封面。动手前建议先抽 3 帧（开头 / 中段 / 结尾）对比，再决定是否重渲全部课程。
