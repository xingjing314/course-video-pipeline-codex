# 视频画面规范 V0.2

更新日期：2026-11-02。适用于本项目各课时的画面制作。

本规范合并原头尾区域、背景和章节主标题规范，并统一规定口播字幕外观。字幕文字与时间见[字幕规范](字幕规范V0.2.md)，音频和真题思考停顿见[音频规范](音频规范V0.2.md)。组件入口与调用方式查[公共能力索引](公共能力索引V0.1.md)。

## 一、画幅、字体与布局边界

画幅为 **1920 × 1080，30 fps**。显式使用 `"Noto Sans CJK SC", sans-serif`，避免系统回退到不合适的中文字形。

| 区域 | 基准位置与范围 |
| --- | --- |
| 头部导航 | `top: 14`、高 `32`，左右各 `96` |
| 场景标题区 | `top: 48` 起，左右各 `96` |
| 教学内容外边界 | `x: 96–1824`、`y: 110–900`，宽 `1728`、高 `790` |
| 底部口播字幕 | 左右各 `160`、`bottom: 34`，具体盒模型见第六节 |

标题区与教学内容范围不是互不相交的固定矩形。内容布局需避开实际标题占用；所有教学元素的底边不超过 **y=900**，不得侵占字幕槽。导航、字幕固定，内容运镜不带动这两层。

通用文字色为 `#E6F1FA`，辅助文字色为 `#8FB8D9`；导航使用青色 `#2EC4D6` 和金色 `#E0B050`。章节主标题的专用配色见第五节。

## 二、背景

统一复用现有 `TechNetwork`（类型 `tech-network`），采用以下基准：

| 参数 | 值 |
| --- | --- |
| `ganttEnabled` | `false` |
| `linkOpacity` | `0.035` |
| `nodeOpacity` | `0.06` |
| `highlightCoreOpacity` | `0.1` |
| `highlightGlowOpacity` | `0.06` |

其他参数沿用 `techNetworkSchema` 默认值，底色中心为 `#0B1A33`、边缘为 `#060E1F`，循环周期为 30 秒。只传 `type` 不等于采用本规范：现有 Schema 的甘特条和部分透明度默认值与上述基准不同。

每个可见画面只保留一层整屏背景，位于教学内容、导航和字幕之下。保留现有缓慢运动与纹理，不额外叠加闪烁、强光、装饰文字，也不用截图代替动态背景。局部半透明面板可以按教学需要使用。

改变背景类型、动画或基准参数时，先说明原因并提供小样，按原有审核节点确认。课时局部布局问题不通过改写公共背景解决。

## 三、头部导航

导航包含四项：左侧课程码和课程名，右侧当前段落名与 `镜号 · 当前序号/总数`。内容来自本课数据，课程名不带稿件版本等制作说明。

| 元素 | 字号 / 字重 | 样式 |
| --- | --- | --- |
| 课程码 | `14 / 700` | 大写课时标识；青色文字，底色透明度 `0.16`、`1px` 描边透明度 `0.45`、圆角 `6`、内边距 `2px 10px`、字距 `1` |
| 课程名 | `15 / 500` | 辅助文字色，与课程码间距 `12` |
| 段落名 | `14 / 400` | 辅助文字色，与进度胶囊间距 `10` |
| 进度胶囊 | `14 / 700` | 导航金色文字，底色透明度 `0.18`、`1px` 描边透明度 `0.5`、圆角 `999`、内边距 `2px 10px` |

两端对齐，`zIndex: 10`，`pointerEvents: none`。有声版与无声版都保留导航。

采用 `MasterCanvas` 的课时，一场景一分镜可用 `headerMode: "scene"`；一个渲染段跨多分镜时用 `chapter`，由段组件按实际分镜推进导航，母版不重复绘制。其他入口同样保证镜号随画面更新。

## 四、场景标题

场景标题由编号、标题和可选副标题组成，与第五节的章节主标题分开使用。

| 元素 | 参数 |
| --- | --- |
| 编号 `eyebrow` | 字号 `20`、字距 `3`、辅助文字色，编号最多三级，`marginBottom: 10` |
| 标题 `title` | 字号 `46`、字重 `700`、字距 `1.2`、通用文字色，建议不超过 22 字 |
| 副标题 `subtitle` | 字号 `24`、辅助文字色，`marginTop: 8`、`maxWidth: 1500`，建议不超过 40 字 |

导航文字与标题首行保留约 **14px 的视觉间隙**，按实际字形判断，不将两个定位框的 `top` 差直接当作视觉间距。复用已确认布局时沿用结果；改变字号或落位后再检查。

## 五、章节主标题

仅规定“章节标签＋主标题文字＋底部装饰线”组合。章节编号和标题使用本课内容，整体位置随本课布局安排。

| 部分 | 样式参数 |
| --- | --- |
| 组合 | 横向 flex、垂直居中，`gap: 28px`、`padding-bottom: 16px`，宽度随内容展开 |
| 章节标签 | 字号 `34px`、字重 `650`、字距 `2px`，颜色 `#E6B65F`；内边距 `10px 20px`，圆角 `12px`，描边 `1px solid #E6B65F85`，底色 `#E6B65F12`，行高沿用默认值 |
| 主标题 | 字号 `68px`、字重 `700`、行高 `1.2`、字距 `4px`，颜色 `#E6F1FA`，阴影 `0 3px 18px #46D6E318` |
| 装饰线 | 相对组合绝对定位，`left: 0; right: 0; bottom: 0`、高 `2px`；渐变 `linear-gradient(90deg, #E6B65FB3, #46D6E366 55%, transparent)` |

用布局间距分隔标签与标题，不用空格定位。保留颜色中的透明度，装饰线跟随组合宽度。本组合规定静态样式，不要求增加入场或循环动画。

## 六、口播字幕外观

| 参数 | 值 |
| --- | --- |
| 外层定位 | `left: 160; right: 160; bottom: 34`，水平居中 |
| 字幕盒 | 内容自适应，`maxWidth: 1520`，内边距 `12px 30px`、圆角 `14` |
| 文字 | 字号 `28`、字重 `600`、行高 `1.4`、字距 `0.8`，通用文字色，居中 |
| 底板 | `rgba(4,10,24,0.86)` |
| 描边 | `1.5px`，青色透明度 `0.42` |
| 阴影 | `0 8px 28px rgba(0,0,0,0.45)` |
| 层级与交互 | `zIndex: 20`、`pointerEvents: none` |
| 行数 | 优先 1 行，最多 2 行 |

按此盒模型，1 行约高 `66px`、顶部约 `y=980`；2 行约高 `105px`、顶部约 `y=941`，与教学舞台底边至少保留约 `41px`。长字幕按字幕规范切分，不靠缩小字号或挤占教学区处理。

无声无口播字幕版关闭口播字幕，保留导航、题面、解析、图形和倒计时等教学内容。思考停顿期间保留中性题面并清空口播字幕，停顿时序统一按音频规范执行。

## 七、制作与检查

优先复用已有组件和已确认配置，按本课内容覆盖参数。组件默认值不等于规范值，具体支持范围查公共能力索引。

在原有分组预览节点检查：背景只有一层且不干扰阅读；导航与镜号正确；标题和教学内容互不遮挡；字幕最多两行；固定导航和字幕不随内容运镜。静帧检查布局，连续播放检查节奏与入退场。

本版沿用已确认的视觉基准。改动后只复核受影响的画面与预览，不因规范整理自动重做已交付课程。
