# 课时制作：Agent 接手与协作说明 V0.1

更新日期：2026-11-02。适用于独立接手课时、迁移工作环境或多人协作。

常规制作按 [AI互动流程总结](AI互动流程总结V0.1.md)执行；本说明只补充工作目录、素材和协作要求，按当前需要阅读。

## 一、接手时了解当前任务

遵守 [AGENTS.md](../../AGENTS.md)，从用户指令和现有课时记录中了解：

- **任务**：课时标识、输入稿路径与版本、本轮范围和停止点、已通过的内容与待办。
- **工作环境**：实际工作目录、预览端口和 Composition；使用 Git 时记录分支与基线提交。
- **协作条件**：本轮必需素材的位置与缺项；多人协作时明确各自负责范围和负责整合者。

沿用已有授权与审核结论，不另填任务卡。缺少的信息影响当前工作时再询问；首次反馈简要说明接手状态、下一步和实际阻碍。

## 二、准备独立工作目录与素材

1. 沿用已分配的工作目录。需要同时编辑时，使用独立分支和 worktree，或用户选定的项目副本，并分开输出目录；在同一目录切换分支不能隔离同时写入。
2. 使用 worktree 时先核对来源提交。未提交的修改和未跟踪文件不会自动进入新目录，由整合者按已有授权准备本轮需要的基线，保留其他未完成改动。
3. 检查自己的工作目录和已有修改，按需安装锁文件指定的依赖。环境准备见 [README](../../README.md)的“安装与预览”和“外部环境与素材依赖”，只检查本轮需要的 Node、浏览器、TTS、对齐器或媒体工具。
4. 按课恢复所需音频、教材图和其他本地素材，保持代码引用的相对路径。代码存在不代表素材齐全；新生成的文件写入自己的课时目录，不把其他任务的可写素材目录链接为自己的输出。
5. 项目内 skill 保留完整目录、所需附件和许可文件；环境提供的 skill 不会随项目复制，按当前任务确认是否可用。历史案例和可选参考工具不作为运行依赖。

## 三、哪些文件属于本课

目录约定见 AI互动流程总结第四节，沿用本课实际课号与工作区标识。按以下范围协作：

| 文件范围 | 修改方式 |
| --- | --- |
| 本课组件、数据和制作记录 | 在本轮授权范围内维护；专用组件放在 `src/lessons/<章节>/<课时>/`，确有需要的专用脚本放在 `scripts/<lessonId>/` |
| 章节汇总、公共注册、`src/visual/`、`contracts/`、共享脚本和配置 | 确需修改时说明原因、影响和差异，由负责整合者协调修改与合并，避免多个任务各写一套 |
| 其他课时的内容与成果 | 保留既有入口、已确认素材和版本；只在确实阻碍本轮目标且属于授权范围时处理 |

公共组件与方法优先按 [公共能力索引](公共能力索引V0.1.md)复用，课时专用逻辑留在本课目录。`current-lesson.json` 等运行配置只在各自工作目录使用，不作为不同任务共用的可写入口。

## 四、复用现有导出入口

新课接入查公共能力索引第八节，Studio 与导出命令查第九节。按本课实际注册方式接入，保留已有 Composition ID，不为接手统一改写不同课时的制作方式。

Studio 从自己的项目根目录启动，使用空闲端口和本课 Composition；端口被占用时换端口，不停止其他任务的服务。复用现有预览、渲染脚本，参数按本课路径与时间轴填写，不复制整份旧课脚本。

## 五、审核节点与反馈方式

制作步骤、分组审核、GPU 分工和交付清单统一按 AI互动流程总结执行；展示与字幕规则按其中列出的适用规范，思考停顿和音频要求见 [音频规范V0.2](音频规范V0.2.md)。

多人共用 GPU 时，由用户安排重型 TTS、对齐和视频导出错峰执行。遇到环境、权限或素材障碍，说明具体原因、最小处理操作和需要返回的结果，继续推进不受影响的工作。

交接进度写入现有课时记录，注明预览入口、用户结论、实际修改和剩余工作。技术检查、用户视听审核分别记录；接手后沿用已确认部分，只复核改动及受影响内容。

## 六、交付、代码与媒体分别保存

移交时提供能够继续本轮工作的代码、数据、素材和记录：

| 内容 | 保存与移交 |
| --- | --- |
| 代码与课时数据 | 按现有 Git 约定保存代码、课程数据、SRT、制作记录和选图 JSON；使用 Git 时关联对应提交 |
| 本地素材与媒体 | 音频、成片、讲义 PDF / 位图和修复前备份保存在本地或用户指定的备份位置，交接实际路径与恢复来源 |
| 当前进度 | 记录哪些内容已通过、哪些待审核、尚未完成什么，并关联预览和成果位置 |

提交与上传按已有授权执行。提交前核对差异、拟提交文件和 `.gitignore`，只纳入本轮明确的课时文件及已协调的公共修改，不把其他任务改动或交付媒体一并提交。

媒体与讲义的目录按 AI互动流程总结执行。确认所需素材已移交后，再按用户要求清理旧工作目录；代码合并和 worktree 都不能代替媒体备份。
