# 题卡规范 V0.1

更新日期：2026-11-03。适用于本项目四种公共题卡及其课时组合。

目的：让学生随着口播自然找到正在阅读的内容、理解判断依据，再确认答案。题卡布局服务于题目内容，选项样式随讲解切换；具体题目、时间锚点和解释图留在课时目录。

公共入口与实际接口查[公共能力索引](公共能力索引V0.1.md)第五节。整体画面沿用[视频画面规范](视频画面规范V0.2.md)，思考停顿沿用[音频规范](音频规范V0.2.md)第五节。本规范用于制作题卡时按需阅读，不增加每课重新校准或逐项审批。

## 一、四种题卡的使用与布局

下表左列是 Studio 样式预览的 Composition 名称，代码统一从 [quiz.ts](../../src/visual/templates/quiz.ts) 导入对应组件。

| 预览样式 / 公共组件 | 适用场景 | 布局要求 |
| --- | --- | --- |
| `QuizCardExam` / `ExamQuizCard` | 单题完整讲解、长选项、编号材料或需要展开依据的题目 | 以当前题目为主体，长选项优先单列，短选项可双列；编号材料与组合选项分清层级，为必要解释保留空间。倒计时旁不加“先自己选” |
| `QuizCardDual` / `DualQuizBattleCard` | 两道题围绕同一知识点进行比较 | 左右题卡等宽、字号标准一致，各题使用自己的阅读、思考和揭示时点；讲一题时另一题仍可读。比较结论在对应讲解时出现，不能使另一题提前泄露答案 |
| `QuizCardCompact` / `CompactQuizCard` | 题卡与图解组合，或当前题与对照题并排 | 并排时左右题卡一样大；通过边框、底色等转移焦点，保留对照内容的可读性。题目放不下时调整布局或选用 Exam，不靠持续缩小字号容纳 |
| `QuizCardBrief` / `BriefQuizCard` | 短题、复习卡、同考点补充题 | 沿用已有简版样式，支持多卡组合；四卡只是预览实例。逐题处理阅读与揭示，较复杂的材料、长选项和解释不强塞进简版卡 |

题面、选项和来源必须完整。重点转移时保持选项顺序与位置稳定，增强样式不应让其他行反复跳动。题目长短不改变三秒思考时长。

## 二、题面显示与口播聚焦

完整题面和全部选项可以先显示，再由口播带动阅读焦点。需要逐步建立信息时，也可以随口播出现相应内容；已出现且仍需比较的内容继续保留。**不要求四种题卡一律逐项隐藏、出现。** 进入思考阶段时，题干、材料和可供判断的选项必须完整可读。

朗读 A 时聚焦 A，转到 B 时将阅读焦点交给 B。组合题先跟随编号材料，再跟随 A—D 组合选项；材料编号与选项字母分别定位，不能混成同一组状态。没有朗读的内容不凭固定时间轮流闪亮。

阅读强调表示“正在读这里”，不表示正确或错误。已经读过的内容退回普通样式；读题结束后结束阅读强调，思考时让学生自行比较。讲解中的再次提及使用当时的解释焦点，不沿用读题时最后一项的强调。

## 三、选项样式的含义与切换

以下为默认视觉含义，课时可覆盖配色和强度，但同一课中必须保持含义一致，不能仅靠颜色传递答案或正误。

| 状态 | 何时使用 | 默认呈现 |
| --- | --- | --- |
| 普通题面 | 尚未聚焦、已读完或作为参照 | 深色底板、蓝色或中性边框，文字清楚可读 |
| 阅读焦点 | 正在朗读该项或编号材料 | 金色边框、轻底色与序号强调，可配细侧边标记；不出现答案标签、勾叉或纠错说明 |
| 思考 | 实际三秒静音窗口 | 完整中性题面与倒计时，关闭阅读焦点和解析内容，口播字幕为空 |
| 解释与对照 | 讲到某项的含义、适用条件或与另一项的区别 | 聚焦对应词句或对象；比较可用蓝色，判断依据可用下划线、短注释或关系图，按口播逐步展开 |
| 表述判断 | 已讲到该项或词句的正误 | 正确表述可用绿色，错误表述可用红色并指出具体问题；标记与该项的讲解同步，未讲到的项不一起判定 |
| 本题答案 | 口播明确给出答案 | 明确显示“本题答案”或等义标签，保留理解所需的题面和依据；与“表述正确 / 错误”的含义区分 |

阅读焦点转移后，已完成的正误判断可保留为参照；当前讲解对象仍须容易找到。避免同时让所有选项强亮、连续闪动，或把其余文字压暗到难以阅读。颜色、字重、边框、底色与标记按需要配合，不要求每次叠加全部效果。

负向题尤其要区分“表述错误”与“应当选择”：错误表述可以保留红色，同时明确标注“本题答案”；不能让学生把红色理解成“这项不能选”。公共数据中 `polarity="negative"` 时，`isCorrect` 表示表述本身是否正确。

## 四、时序与解释依据

1. 阅读、解释、判断和答案分别绑定实际口播短语或已有对齐数据，沿用本课时间轴。组件默认的固定错峰入场只是入场动效，不能当作已经跟随口播。
2. 三秒思考窗口按音频规范定位：需要朗读选项时，在题干和这些选项读完后安排；不朗读选项时，在题干读完后安排。画面倒计时使用同一真实静音窗口。
3. 答案揭示与逐项判断服从已确认口播的顺序。口播先给答案再解释时按该顺序展示，不为套用固定动画流程改写配音或重排讲解。
4. 讲到哪个错误词才标记哪个词，讲到哪条依据才出现相应解释。依据来自已确认口播、教材与题目；关系图须帮助学生看清原因或区别，不能只增加装饰。
5. 同一选项的展示、阅读焦点、判定和解释可以分别安排，具体时点属于课时数据。组装时统一处理局部时间与全局偏移，不照抄示例帧号。

## 五、复用方式与现有实例

优先用公共组件的参数、组合与已有插槽完成课程设计。公共题卡负责布局与通用呈现，课时负责题目内容、实际时点、判断依据和专用图解。只有确认接口缺口时才补充公共能力，不为每课复制整套题卡。

目前 `ExamQuizCard` 的 `renderOption` 和 `renderStatement` 可替换选项行与编号材料，保留公共题干、布局和倒计时。使用插槽时，调用方负责该部分的阅读、判定与答案样式。其他三种题卡尚无同等的逐项阅读焦点接口；`CompactQuizCard.active` 控制整张卡，不能当作单个选项的阅读状态。规范中的呈现要求不代表所有组件已提供同名参数，使用前按索引核对实际接口。

以下均为当前项目 `ch08/L03` 的参考实例，提炼呈现方法即可，具体选项、配色取值、字号与时间不作为所有课程的固定配置：

| 实例 | 可参考的做法 |
| --- | --- |
| [G01V2.tsx](../../src/lessons/ch08/L03/G01V2.tsx) 的题卡 | 长选项跟读聚焦；错误词局部标注；区分负向题答案与其他正确表述；用职责关系图说明判断依据 |
| [G02Quiz.tsx](../../src/lessons/ch08/L03/G02Quiz.tsx) | 编号材料与组合选项分别跟读；讲解时逐项分类，再用图示归纳依据 |
| [G05Quiz.tsx](../../src/lessons/ch08/L03/G05Quiz.tsx) | 阅读、答案和对照对象分别强调；用人物、文档和连线展示两类工具的区别 |

## 六、检查与审核

沿用本组 Studio 审核节点，检查代表性的读题、焦点切换、思考、解释和答案状态，无需逐帧或逐项增加审批。

- 对照实际配音：聚焦的是正在讲的内容，判断和解释没有提前；读题结束后不残留最后一个选项的阅读强调。
- 从学生视角：完整题面可读，普通项、阅读焦点、正误和本题答案容易区分，解释图与对应选项有明确联系。
- 对多题布局：左右或多张题卡各自的时点正确，讲解一题不提前判定其他题。
- 讲义选帧：练习页选完整中性状态，解析页选依据完整的状态，按[教学讲义制作方案](教学讲义制作方案V0.1.md)执行。

只看代码或静帧时，应说明连续音画尚未确认。需要 GPU 渲染或截帧时仍由用户执行；已通过的公共规则直接复用，只复核本次改动及受影响的部分。
