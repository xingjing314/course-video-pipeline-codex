# 题卡规范 V0.1

更新日期：2026-11-06。适用于四种公共题卡及其课时组合。公共组件负责布局与呈现，本课提供题目、实际口播锚点、判断依据和专用图解。

## 一、四种题卡的使用与布局

代码从 [quiz.ts](../../src/visual/templates/quiz.ts) 导入；下表列出 Studio ID 与对应组件。

| 预览 / 公共组件 | 适用场景 | 布局要求 |
| --- | --- | --- |
| `QuizCardExam` / `ExamQuizCard` | 单题完整讲解、长选项或编号材料 | 长选项优先单列，短选项可双列；材料与组合选项分层，为解释保留空间；倒计时旁不加“先自己选” |
| `QuizCardDual` / `DualQuizBattleCard` | 同一知识点的双题比较 | 左右等宽、字号一致，各题独立计时；当前题聚焦时另一题仍可读 |
| `QuizCardCompact` / `CompactQuizCard` | 题卡与图解组合，或题目并排对照 | 并排题卡等宽、题面区域对齐，解析按内容增高；放不下时调整布局或改用 Exam，不持续缩小字号 |
| `QuizCardBrief` / `BriefQuizCard` | 短题、复习与补充题 | 支持多卡组合，四卡仅为预览实例；复杂材料、长选项和长解析使用其他形式 |

题面、选项和来源须完整。焦点交接或标签出现时保持选项顺序与位置稳定。多题使用独立时点：当前题思考时保持中性，先前已揭晓的答案与依据可保留，后续题不提前判定。

## 二、题面显示与口播聚焦

题面可以一开始完整显示，也可随口播逐步建立；进入思考时必须全部可读。已出现且仍需比较的内容继续保留。

阅读焦点跟随实际口播：读 A 时聚焦 A，转到 B 时交接。编号材料与 A—D 组合选项分别定位；未朗读的内容不按固定时间轮流闪亮。已读内容恢复普通样式，思考后继续朗读时可重新聚焦。

## 三、选项样式的含义与切换

配色可覆盖，但同一课内含义一致；正误与答案同时用文字或标签说明。

| 状态 | 默认呈现 |
| --- | --- |
| 普通题面 | 深色底板、中性边框、浅白 `#E6F1FA` 文字 |
| 阅读焦点 | 青色 `#2EC4D6` 边框、轻底色和序号强调；表示正在读，不出现答案标签、勾叉或纠错说明 |
| 思考 | 当前题完整中性，金色 `#E0B050` 倒计时；关闭临时关注与解析，口播字幕为空 |
| 解释与对照 | 青色聚焦当前词句或对照对象，金色强调依据，随讲解展开 |
| 表述判断 | 符合原则用青色，错词、错误判断及排除提示用朱红 `#E0605A`；与该项讲解同步 |
| 本题答案 | 绿色 `#4CC38A` 明确标注“本题答案”或等义文字，保留必要题面与依据 |

临时阅读色可用 `presentation.focusColor` 覆盖，例如改为金色；判断颜色仍表达正误。默认判断标签为“表述正确”“表述有误”等通用文字，具体错因由本课材料提供。

焦点转移后，已完成的判断可保留。避免所有选项同时强亮、连续闪动或把其余内容压暗到无法阅读。

负向题须区分“表述错误”与“本题答案”：允许红色错词与绿色答案章同时保留，并用文字解释。`polarity="negative"` 时，`isCorrect` 表示表述本身是否正确。

## 四、时序与解释依据

1. 阅读、解释、判断和答案有口播时，绑定本课实际短语锚点或对齐数据。固定错峰入场只是动画，不能代替口播同步；不照抄示例帧号。
2. **题干读完立即开始三秒真实静音与倒计时，不等待选项读完。** 题干、材料和全部选项此时完整可见，清除临时阅读强调与口播字幕；停顿结束后继续后续口播。题目长短不改变三秒时长。
3. 判断、解析和答案不得早于思考结束。此后按已确认口播顺序呈现：先给答案再解释也按原顺序展示，不为套用动画流程重排配音。有答案口播时同步揭晓；没有时，由本课明确设置思考结束后的揭晓点，组件不自动猜测。
4. 讲到哪个错词才标记哪个词，讲到哪条依据才显示对应解释。依据来自已确认口播、教材和题目；图解应说明原因或区别。
5. 展示、焦点、判断和解释可分别设定时点。题卡使用局部帧，组装时统一处理全局偏移，避免重复叠加。

题卡只呈现倒计时与状态；音频处理负责三秒真实静音，字幕处理保证整个窗口为空。具体处理见[音频规范第五节](音频规范V0.2.md)。

### 内容完整程度与过渡

| 流程 | 呈现要求 |
| --- | --- |
| 完整解析 | 随讲解逐项显示材料支持的判断与依据 |
| 简短解析 | 仅显示实际提供的短解释 |
| 直接答案 | 完整题面 → 题干读完 → 三秒倒计时 → 按设置时点揭晓 |

无解析时不生成面板或预留空白，不补写未经支持的判断。多条解析按教学需要保留或替换。

`presentation` 的默认过渡为 **0.2 秒**，可用 `transitionSeconds` 覆盖。底色和边框平稳渐变，标签、答案章与解析适度淡入淡出；按 `fps` 和 Remotion 帧计算，不用 CSS transition。答案动画从允许揭晓的帧开始，不为动画提前泄露；标签与解析出现不挤动题干和选项。

## 五、复用方式与现有实例

通过组件参数、组合和插槽接入；确认接口缺口后再补充公共能力，不为每课复制整套题卡。

- `variant="paper"` 使用已确认的完整题面布局；省略时保留原 `stacked` 布局。
- `presentation` 控制公共颜色、焦点、判断、解释与过渡；省略时保留原表现。
- 参数与插槽见[公共能力索引第五节](公共能力索引V0.1.md#五真题展示与时序边界)，整体画面遵循[视频画面规范](视频画面规范V0.2.md)。

调用代码与独立预览见[完整公共示例](../../src/examples/quiz/README.md)。示例无配音，固定时序用于演示，不能代替正式课时的真实音画同步验证。

## 六、检查与审核

沿用本组 Studio 审核节点，检查本次改动影响的读题、焦点交接、思考、解释和答案状态：

- **同步**：关注对象与口播一致；思考从题干结束开始，完整三秒静音且字幕为空；判断、解释和答案不提前。
- **可读性**：题面完整，阅读焦点、正误和答案易于区分，解释图对应明确，切换不挤动文字。
- **多题时序**：各题独立计时，讲解当前题不提前判定其他题，已揭晓内容按需要保留。
- **讲义选帧**：练习取完整中性状态，解析取依据完整的状态，按[教学讲义制作方案](教学讲义制作方案V0.1.md)执行。

仅检查代码或静帧时须注明连续音画未验证。需要 GPU 渲染或截帧时由用户执行。
