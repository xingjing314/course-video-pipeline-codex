# 公共能力更新建议 V0.1

适用项目：`course-video-pipeline-codex`  
更新日期：2026-11-02  
状态：公共能力索引已建立；公共实现完善与导出改造仍按具体改进项推进，不视为全部完成。

**仅在规划或实施公共能力改造时阅读，不列入日常课时制作必读。** 现有能力、调用入口与限制查[公共能力索引](公共能力索引V0.1.md)。

目标是复用公共组件与命令，减少重复渲染，把时间用于教学画面设计和制作。改动范围以当前项目的 `src` 和必要的 `scripts` 入口为主，沿用现有目录与工作方式，不扩大为整条流水线重构，不修改 `course-video-pipeline-codex-deepseek` 项目。

## 1. 明确公共代码与课时专用代码的边界

沿用已有划分：`src/visual` 承载原子组件、组合组件、公共布局与展示能力；`src/lessons/<章节>/<课时>/` 承载课程内容、分镜、专用图解、动画安排与实际时间数据。

后续按实际复用需要，将写死的课程内容与通用能力分开。课时专用设计继续调用已有原子组件和公共方法；只使用一次且没有独立封装价值的逻辑留在课时目录。

## 2. 完善默认值、参数覆盖和局部替换

已有接口直接复用，需要完善的接口按实际需求支持：

- 有公共默认值的可选参数可以省略，课程需要时可以覆盖。
- 使用现有组件组合表达课程差异。
- 局部表现需要变化时，开放对应内容或渲染部分的替换方式。

必填输入仍按实际接口提供，不把所有参数都改成可选。“可插拔”通过现有组件与参数机制实现，不另建复杂继承体系；公共默认值应符合现行规范。

## 3. 将共同规范与真题规则落实到公共实现

依据[视频画面规范V0.2](视频画面规范V0.2.md)、[字幕规范V0.2](字幕规范V0.2.md)、[音频规范V0.2](音频规范V0.2.md)，修正公共背景默认值、字幕样式和布局中实际不一致的部分。

真题的中性读题、思考停顿、倒计时和答案揭示按音频规范第五节落实为可复用能力。各课提供题目、选项、答案，以及读题结束、讲解开始等实际时间，公共实现执行共同规则。

题目长短不改变约定的思考时长，特殊图解留在课时设计。公共规则确认后复用，只检查实际改动及受影响部分，不要求每节课重新校准。

## 4. 维护公共调用入口与现有索引

[公共能力索引](公共能力索引V0.1.md)已经建立，记录现有组件、方法、命令和使用限制。

后续新增公共能力或改变接口时，同步更新对应条目的用途、入口、必填参数、默认行为、可覆盖项和必要示例。已完成的改进更新实际状态；尚未实现的能力继续记录为建议，不提前列为可用接口，也不为补齐索引创建空实现。

## 5. 完善可按组执行的 GPU 命令

复用已有脚本与执行入口，按实际需要补充课时、分组或音频段选择参数，复用已有结果，减少每节课重复编写专用脚本。现有命令支持范围以索引为准。

命令准备、用户执行 GPU 步骤和结果核对按[AI互动流程总结](AI互动流程总结V0.1.md)第三节协作。步骤是否合并取决于实际依赖，不预先要求合成一个大命令；不能照搬其他项目的专用路径和参数。

## 6. 调整双版本导出，减少重复渲染

项目已有独立音频和字幕数据，现有双版本导出仍分别渲染画面。待实施方向为：

1. 完整渲染一次 `silent-clean.mp4`，保留教学内容，不含音轨和口播字幕。
2. 复用同一时间轴的 `full.wav` 与字幕数据。
3. 在干净视频上合成配音和字幕，生成 `voiced-captioned.mp4`。
4. WAV、SRT 和 JSON 说明继续独立交付，目录与成果要求沿用 AI互动流程总结。

合成字幕的外观须符合视频画面规范第六节。带字幕版仍需处理画面并重新编码，节省的是再次计算教学组件、布局和动画的工作；实现后用小样验证效果与耗时，不预先承诺固定提速幅度，也不要求每课重复做性能校准。

保留干净版作为合成输入；已烧录字幕的有声版不能通过关闭字幕轨恢复为干净版。独立交付的音频和字幕继续使用原始文件。

## 7. 暂时保留的做法

- **TTS 命令暂不因 FlashAttention 警告而修改。** 保留现有调用方式，不为消除警告直接安装或替换注意力后端。
- **视频分段渲染沿用现有方式。** 暂不新增五组同时运行的机制。

按本轮明确范围逐项实施并更新相关索引与状态；整理本文件不代表代码改造已经完成。
