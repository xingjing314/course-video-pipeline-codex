## 一、组成与视觉关系

标题由三个元素构成：

- **章节标签**：“第六章”，金色文字、淡金色透明底、细描边圆角框。
- **主标题**：“项目管理概论”，浅色大字，与章节标签横向排列、垂直居中。
- **底部装饰线**：贯穿整个标题组合，从金色过渡到青色，再淡出至透明。

文字完整读作 **“第六章 项目管理概论”**。两段文字之间用布局间距分隔，不靠添加空格定位。主标题是视觉重点，章节标签用于识别章节。

本文不规定整屏背景、头部导航、上方场景标题、正文卡片、字幕或其他画面元素。

## 二、已确认的样式参数

尺寸以当前 **1920 × 1080** 画幅中的像素为基准，字体为 `"Noto Sans CJK SC", sans-serif`。

### 2.1 标题组合

| 属性 | 值 |
| :--- | :--- |
| 排列 | `display: flex`，`alignItems: center` |
| 标签与主标题间距 | `gap: 28px` |
| 底部留白 | `padding-bottom: 16px` |
| 宽度 | 随文字内容展开，装饰线跟随组合宽度 |
| 当前开场位置 | `position: absolute; left: 96px; top: 238px` |

位置是当前开场的落位记录，不作为整屏布局规范；在其他画面使用时可随内容布局调整。

### 2.2 章节标签“第六章”

| 属性 | 值 |
| :--- | :--- |
| 字号 / 字重 | `34px` / `650` |
| 字距 | `2px` |
| 文字颜色 | 金色 `#E6B65F` |
| 内边距 | 上下 `10px`，左右 `20px` |
| 描边 | `1px solid #E6B65F85` |
| 圆角 | `12px` |
| 背景 | `#E6B65F12`，淡金色透明底 |
| 行高 | 沿用当前默认值，未单独设置 |

### 2.3 主标题“项目管理概论”

| 属性 | 值 |
| :--- | :--- |
| 字号 / 字重 | `68px` / `700` |
| 行高 | `1.2` |
| 字距 | `4px` |
| 文字颜色 | `#E6F1FA`（当前实现继承自父级） |
| 文字阴影 | `0 3px 18px #46D6E318`，轻微青色光晕 |

### 2.4 底部装饰线

| 属性 | 值 |
| :--- | :--- |
| 定位 | 相对标题组合绝对定位，`left: 0; right: 0; bottom: 0` |
| 高度 | `2px` |
| 渐变 | `linear-gradient(90deg, #E6B65FB3, #46D6E366 55%, transparent)` |

上述八位十六进制颜色末两位为透明度，应保留原值，避免把标签背景、描边或光晕改为不透明色块。

## 三、实现参考

以下仅包含该标题块；字体与主标题颜色显式写出，便于复现当前继承得到的效果。

```tsx
<div style={{
  position: "absolute", left: 96, top: 238,
  display: "flex", alignItems: "center", gap: 28,
  paddingBottom: 16,
  fontFamily: '"Noto Sans CJK SC", sans-serif',
}}>
  <span style={{
    fontSize: 34, fontWeight: 650, letterSpacing: 2,
    color: "#E6B65F", padding: "10px 20px",
    border: "1px solid #E6B65F85", borderRadius: 12,
    background: "#E6B65F12",
  }}>第六章</span>
  <span style={{
    fontSize: 68, lineHeight: 1.2, fontWeight: 700,
    letterSpacing: 4, color: "#E6F1FA",
    textShadow: "0 3px 18px #46D6E318",
  }}>项目管理概论</span>
  <div style={{
    position: "absolute", left: 0, right: 0, bottom: 0,
    height: 2,
    background: "linear-gradient(90deg, #E6B65FB3, #46D6E366 55%, transparent)",
  }}/>
</div>
```

标题块本身未设置单独的入场或循环动画。本规范记录已确认的静态样式。
