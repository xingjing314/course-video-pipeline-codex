按当前进度选择一段，替换课时和范围即可；每段沿用项目 AGENTS.md 与制作流程对应阶段。

## 第 1 轮：接手

亲爱的，项目目录：/projects/gaoxiang/course-video-pipeline-codex
本课：<课时目录>
本轮任务：<要完成什么>

请读 AGENTS.md 和 docs/architecture/AI互动流程总结V0.1.md 第一节，从本课已有记录了解进度与审核结论，简要说明接下来做什么。具体材料和实现留到对应阶段查阅。本轮只读。

## 第 2 轮：理解本课内容

亲爱的，请阅读 docs/lessons/<章节>/<课时>/input/ 中的口播稿、口播与画面分镜合一稿和必读清单，按本课范围阅读清单指定的教材章节、图表和题目。

简要说明教学目标、讲解结构，以及画面需要帮助学生理解什么。口播决定讲解顺序与配音正文，教材和题目提供依据；影响制作的缺失或冲突请指出具体位置。本轮先理解内容，不改稿或制作。

## 第 3 轮：讨论并确认分镜与分组

亲爱的，基于本课材料，使用教学画面编排 skill 提出整课分镜与分组方案。

围绕学生需要理解的对象、关系和变化安排画面。每镜说明口播范围、教学目的、主要画面关系及重点转移；按讲解完整性分组，列出组号、镜号和主题，提出首组小样范围。时机先用口播短语描述；接口影响设计时查公共能力索引。

本课如有“讲师口播与画面分镜合一稿”，仅作可选参考。先在对话中讨论，确认后将方案 V0.1 保存到 docs/lessons/<章节>/<课时>/；本轮不运行制作。

## 第 4 轮：逐组制作与 Studio 审核

亲爱的，请按已确认方案继续制作。

分镜方案：<方案文件路径及所在章节>
制作范围：<组号或镜号范围>

从范围内当前未完成或待审核的组继续。按制作流程第二节第 3 步完成动态画面、实际配音、对齐、字幕和必要关键帧。让画面承担解释工作，入退场与重点变化跟随实际口播；关键帧与连续播放结合自查。

交付可连续播放的 Studio 链接、Composition、分镜范围及审核重点。每组等待我明确通过后再进入下一组；全部分组通过后再进入整课组装。

需要我执行的 GPU 工作，按流程第三节提供完整命令、预期产物及需反馈的日志。

## 第 5 轮：整课组装与正式导出

亲爱的，本课全部分组已通过审核，请按制作流程第二节第 4 步组装与导出。

本课标识：<lessonId>
分镜与分组方案：<方案文件路径>

沿用各组已确认的画面、配音和字幕，用同一组装偏移处理时间轴与思考停顿。调用公共能力索引第 9.2 节的“干净版渲染一次 → 公共合成”流程；已有同版干净视频直接复用。

按流程第三节提供本课实际 GPU 命令。收到结果后核对交付文件、引用同版有效检查报告并补查未覆盖项，记录技术结果与待确认事项；最终连续视听验收由我完成。
